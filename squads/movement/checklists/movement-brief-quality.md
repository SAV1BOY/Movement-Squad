# Qualidade do Brief de Movimento

## Objetivo

Validar que o brief de movimento contém todos os elementos estratégicos necessários para orientar
a criação de um movimento cultural com propósito claro: objetivo definido, audiência mapeada,
crença-alvo identificada, inimigo nomeado, ação desejada e métricas de sucesso estabelecidas.
Um brief incompleto gera execução desalinhada e desperdício de recursos criativos.

## Quando Usar

- Antes de iniciar qualquer projeto de movimento novo
- Quando um brief existente for revisado ou atualizado significativamente
- Na passagem de bastão entre o estrategista e a equipe de execução
- Quando um stakeholder solicitar mudança de direção no movimento
- Em revisões trimestrais de movimentos ativos

## Agentes Responsáveis

- **Movement Strategist Agent** — Autor principal do brief
- **fenomenologo** — Valida insights culturais dentro do brief
- **Review & QA Agent** — Executa este checklist como gate de aprovação
- **Creative Director Agent** — Confirma viabilidade criativa do brief

## Checklist

### 1. Objetivo Estratégico

- [ ] 1.1 O objetivo do movimento está declarado em uma frase única e inequívoca
- [ ] 1.2 O objetivo é mensurável (possui KPI primário vinculado)
- [ ] 1.3 O horizonte temporal do movimento está definido (ex.: 90 dias, 6 meses)
- [ ] 1.4 O objetivo conecta-se explicitamente a um resultado de negócio (vendas, awareness, retenção)
- [ ] 1.5 Existe distinção clara entre objetivo do movimento e objetivo da campanha

### 2. Audiência

- [ ] 2.1 A audiência-alvo primária está descrita com dados demográficos e psicográficos
- [ ] 2.2 Existe pelo menos um verbatim real da audiência documentado (não inventado)
- [ ] 2.3 Os canais onde essa audiência já se reúne estão mapeados (mínimo 3)
- [ ] 2.4 O nível de consciência atual da audiência sobre o problema está classificado
- [ ] 2.5 As objeções previsíveis da audiência estão listadas (mínimo 3)

### 3. Crença-Alvo

- [ ] 3.1 A crença atual da audiência ("antes") está articulada em linguagem coloquial
- [ ] 3.2 A crença desejada ("depois") está articulada com a mesma clareza
- [ ] 3.3 O gap entre crença atual e desejada é realista para o horizonte temporal
- [ ] 3.4 A jornada de mudança de crença possui pelo menos 2 etapas intermediárias

### 4. Inimigo / Tensão

- [ ] 4.1 O inimigo ou tensão cultural está nomeado de forma específica (não genérico)
- [ ] 4.2 O inimigo é algo que a audiência já sente (não precisa ser convencida)
- [ ] 4.3 O inimigo não ataca diretamente um concorrente nominal (evita risco jurídico)
- [ ] 4.4 O inimigo gera indignação suficiente para motivar ação coletiva

### 5. Ação Desejada

- [ ] 5.1 A ação primária que o movimento pede é concreta e realizável em até 5 minutos
- [ ] 5.2 Existe uma ação secundária para quem quer se envolver mais profundamente
- [ ] 5.3 As ações estão sequenciadas (primeiro faça X, depois Y, depois Z)
- [ ] 5.4 O mecanismo de compartilhamento social está embutido na ação

### 6. Métricas de Sucesso

- [ ] 6.1 O KPI primário do movimento está definido com meta numérica
- [ ] 6.2 Existem pelo menos 2 KPIs secundários documentados
- [ ] 6.3 A fonte de dados para cada métrica está identificada (ferramenta, dashboard)
- [ ] 6.4 A cadência de revisão das métricas está definida (semanal, quinzenal)
- [ ] 6.5 Existe um threshold claro de "sucesso" vs "fracasso" para decisão go/no-go

## Critérios de Aprovação

- **Aprovado:** Todos os 25 itens marcados como completos
- **Aprovado com ressalvas:** Máximo 3 itens pendentes, nenhum do grupo "Objetivo Estratégico"
- **Reprovado:** 4 ou mais itens pendentes, ou qualquer item do grupo "Objetivo" faltando

## Ação se Falhar

1. Devolver o brief ao Movement Strategist Agent com os itens faltantes destacados
2. Agendar sessão de refinamento com prazo máximo de 48 horas
3. Bloquear início de produção criativa até aprovação do brief
4. Registrar o gap no log de qualidade para análise de padrões recorrentes
5. Se o brief falhar duas vezes consecutivas, escalar para revisão do framework de briefing
