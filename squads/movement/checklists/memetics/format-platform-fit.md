# Formato Certo para Plataforma Certa

## Objetivo

Garantir que cada peça de conteúdo memético é criada no formato nativo da plataforma
onde será distribuída. Conteúdo cross-postado sem adaptação é sinal de preguiça e
gera performance medíocre em todas as plataformas.

## Checklist

### Mapeamento de Especificações

- [ ] Especificações técnicas de cada plataforma estão documentadas (dimensão, duração, formato de arquivo)
- [ ] Comportamento do usuário por plataforma está mapeado (scroll rápido vs consumo lento)
- [ ] Hora de pico de engajamento por plataforma está identificada com dados
- [ ] Limitações de cada plataforma são conhecidas (caracteres, links, hashtags, músicas)
- [ ] Algoritmo de cada plataforma é estudado e guidelines de distribuição estão atualizados

### Adaptação por Plataforma

- [ ] Instagram: conteúdo é visual-first, texto é complemento (não o contrário)
- [ ] TikTok: vídeos seguem trends de formato/áudio, primeiros 2 segundos capturam atenção
- [ ] LinkedIn: tom é profissional mas humano, storytelling pessoal performa melhor
- [ ] Twitter/X: mensagem é compacta, provocativa e conversacional (incita reply)
- [ ] YouTube: thumbnails e títulos são otimizados para CTR, retenção é prioridade

### Conteúdo Nativo vs Adaptado

- [ ] Pelo menos 50% do conteúdo é criado nativamente para a plataforma (não adaptação)
- [ ] Adaptações entre plataformas são significativas (não apenas resize de imagem)
- [ ] Cada plataforma tem pelo menos 1 tipo de conteúdo exclusivo (não encontrado em outra)
- [ ] O "gancinho" de cada peça é ajustado ao comportamento da plataforma
- [ ] Legendas, CTAs e hashtags são customizados por plataforma

### Monitoramento de Performance Nativa

- [ ] Engajamento por plataforma é comparado com benchmark da plataforma (não entre plataformas)
- [ ] Conteúdo nativo vs adaptado tem performance comparada mensalmente
- [ ] Plataformas com performance consistentemente baixa são reavaliadas (sair é opção)
- [ ] Novos formatos lançados pelas plataformas são testados em até 2 semanas
- [ ] A equipe tem especialista ou responsável dedicado por plataforma principal

## Critérios de Aprovação

- Todos os itens de "Mapeamento de Especificações" devem estar completos
- Todos os itens de "Adaptação por Plataforma" devem estar completos
- Pelo menos 4 de 5 itens de "Conteúdo Nativo" devem estar completos
- Pelo menos 4 de 5 itens de "Monitoramento" devem estar completos

## Ação se Falhar

1. Criar guia de formato por plataforma com exemplos visuais (1 página por plataforma)
2. Eliminar cross-posting direto — todo conteúdo deve ser adaptado ou criado nativamente
3. Analisar top 10 posts de cada plataforma para identificar padrões de sucesso
4. Designar responsável por plataforma que acompanha tendências e mudanças
5. Testar pelo menos 2 formatos nativos novos por plataforma a cada mês
