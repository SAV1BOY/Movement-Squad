# Prontidão de Porta-Vozes

## Objetivo

Garantir que porta-vozes do movimento estão preparados para representá-lo em
qualquer contexto de mídia com competência, coerência e carisma. Porta-voz
despreparado é risco reputacional ambulante.

## Checklist

### Seleção de Porta-Vozes

- [ ] Pelo menos 2 porta-vozes estão identificados e preparados (não depender de 1)
- [ ] Cada porta-voz tem perfil complementar (técnico, carismático, institucional)
- [ ] Porta-vozes representam diversidade (gênero, etnia, senioridade) quando possível
- [ ] Cada porta-voz tem temas de especialidade definidos (quem fala sobre o quê)
- [ ] Existe critério para decidir qual porta-voz usar em cada situação

### Preparação e Treinamento

- [ ] Porta-vozes passaram por media training nos últimos 6 meses
- [ ] Mensagens-chave (3-5 pontos inegociáveis) estão memorizadas e praticadas
- [ ] Perguntas difíceis mais prováveis estão listadas com respostas preparadas
- [ ] Técnicas de bridging (redirecionar pergunta para mensagem-chave) foram praticadas
- [ ] Simulação de entrevista ao vivo foi realizada com feedback construtivo

### Prontidão Operacional

- [ ] Porta-vozes estão disponíveis com menos de 24h de antecedência (para oportunidades)
- [ ] Agenda dos porta-vozes é visível para equipe de PR
- [ ] Briefing pre-entrevista é preparado para cada aparição (veículo, jornalista, contexto, armadilhas)
- [ ] Porta-voz tem bio atualizada e foto profissional disponíveis
- [ ] Dress code e background para entrevistas por vídeo estão definidos

### Pós-Entrevista

- [ ] Debriefing com porta-voz é feito após cada entrevista (o que disse, como se sentiu)
- [ ] Cobertura publicada é monitorada e comparada com mensagens-chave pretendidas
- [ ] Erros ou declarações fora de tom são identificados e endereçados
- [ ] Aprendizados de cada entrevista alimentam preparação para a próxima
- [ ] Performance de porta-vozes é avaliada semestralmente com feedback estruturado

## Critérios de Aprovação

- Todos os itens de "Seleção" devem estar completos
- Todos os itens de "Preparação e Treinamento" devem estar completos
- Todos os itens de "Prontidão Operacional" devem estar completos
- Todos os itens de "Pós-Entrevista" devem estar completos

## Ação se Falhar

1. Identificar e confirmar pelo menos 2 porta-vozes com disponibilidade
2. Agendar media training em até 30 dias (interno ou com profissional externo)
3. Criar documento de mensagens-chave e FAQ com respostas para perguntas difíceis
4. Realizar pelo menos 1 simulação de entrevista gravada com feedback
5. Preparar kit do porta-voz: bio, foto, mensagens-chave, dress code guide
