# Planos de Mitigação de Backlash

## Objetivo

Preparar planos de resposta para cenários de backlash público contra o movimento,
minimizando dano reputacional e preservando a integridade da narrativa. Todo
movimento com posicionamento forte atrai oposição — a questão é estar preparado.

## Checklist

### Mapeamento de Cenários

- [ ] Pelo menos 5 cenários de backlash mais prováveis estão documentados
- [ ] Cada cenário tem: trigger (o que causa), audiência (quem reage), severidade (1-5)
- [ ] Cenários cobrem: crítica legítima, desinformação, ataque coordenado, erro interno, cancelamento
- [ ] Para cada cenário, o "pior caso" está descrito (até onde pode escalar)
- [ ] Cenários são revisados trimestralmente ou após cada ação de alto risco

### Planos de Resposta

- [ ] Cada cenário tem plano de resposta pré-aprovado com 3 opções: responder, esclarecer, silenciar
- [ ] Critérios para escolher entre as opções estão documentados
- [ ] Templates de comunicado para cada cenário estão redigidos e revisados pelo jurídico
- [ ] Tom de resposta está definido: transparente, empático, firme (nunca arrogante ou evasivo)
- [ ] Timeline de resposta por severidade: nível 1-2 em 24h, nível 3-4 em 4h, nível 5 em 1h

### Infraestrutura de Resposta

- [ ] Monitoramento de menções negativas está ativo com alertas em tempo real
- [ ] Equipe de resposta rápida está definida com roles claros (decisor, redator, aprovador)
- [ ] Canal de comunicação interna para crise está testado e acessível
- [ ] Aliados externos (jornalistas amigos, creators, parceiros) estão identificados para suporte
- [ ] Assessoria jurídica está acessível em menos de 2 horas quando necessário

### Pós-Backlash

- [ ] Monitoramento reforçado é mantido por pelo menos 2 semanas após o evento
- [ ] Retrospectiva é conduzida em até 5 dias para extrair aprendizados
- [ ] Impacto em métricas (seguidores, engajamento, sentimento) é medido e reportado
- [ ] Comunidade recebe comunicação honesta sobre o que aconteceu e o que mudou
- [ ] Planos de resposta são atualizados com aprendizados do evento real

## Critérios de Aprovação

- Todos os itens de "Mapeamento de Cenários" devem estar completos
- Todos os itens de "Planos de Resposta" devem estar completos
- Todos os itens de "Infraestrutura" devem estar completos
- Todos os itens de "Pós-Backlash" devem estar completos

## Ação se Falhar

1. URGENTE: listar top 3 cenários de backlash mais prováveis e criar plano para cada
2. Redigir 3 templates de comunicado genéricos adaptáveis (correção, esclarecimento, posicionamento)
3. Configurar monitoramento de sentimento com alertas para menções negativas em volume
4. Identificar 5 aliados externos que podem ser acionados em caso de crise
5. Realizar simulação de backlash com equipe para testar velocidade e qualidade de resposta
