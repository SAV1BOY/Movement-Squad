# Artefatos e Rituais do Movimento

## Objetivo

Verificar que os artefatos (objetos tangíveis e simbólicos) e rituais (ações recorrentes)
do movimento estão alinhados à identidade e cumprem função de fortalecer pertencimento.
Artefato desalinhado confunde; ritual sem propósito cansa.

## Checklist

### Artefatos Simbólicos

- [ ] Pelo menos 3 artefatos visuais existem (logo, badge, template, sticker, wallpaper)
- [ ] Cada artefato comunica a tese do movimento sem precisar de explicação
- [ ] Artefatos são facilmente remixáveis pela comunidade (formatos editáveis disponíveis)
- [ ] Existe guia de uso dos artefatos (o que pode e não pode ser alterado)
- [ ] Artefatos foram testados com público-alvo e validados qualitativamente

### Rituais de Comunidade

- [ ] Existe pelo menos 1 ritual semanal (live, thread, challenge, quiz)
- [ ] Existe pelo menos 1 ritual mensal (encontro, retrospectiva, celebração)
- [ ] Cada ritual tem duração definida (não se arrasta indefinidamente)
- [ ] Cada ritual tem responsável de execução e facilitador nomeado
- [ ] Rituais geram output documentável (resumo, post, artefato derivado)

### Alinhamento Identidade-Artefato-Ritual

- [ ] Cada artefato reforça pelo menos 1 dos 3 pilares do movimento
- [ ] Cada ritual ativa pelo menos 1 emoção conectada à identidade (orgulho, pertencimento, urgência)
- [ ] Linguagem usada nos rituais é coerente com o manifesto
- [ ] Novos membros conseguem participar de rituais sem onboarding extenso
- [ ] Artefatos e rituais são revisados trimestralmente para evitar fadiga

### Evolução e Descontinuação

- [ ] Existe processo para criar novos rituais (proposta → teste → avaliação → oficialização)
- [ ] Existe processo para aposentar rituais (critérios: < 30% participação por 3 edições)
- [ ] Artefatos desatualizados são removidos de circulação ativamente
- [ ] Feedback de participantes de rituais é coletado após cada edição

## Critérios de Aprovação

- Todos os itens de "Artefatos Simbólicos" devem estar completos
- Pelo menos 4 de 5 itens de "Rituais de Comunidade" devem estar completos
- Todos os itens de "Alinhamento" devem estar completos
- Pelo menos 3 de 4 itens de "Evolução" devem estar completos

## Ação se Falhar

1. Realizar workshop de co-criação de artefatos com 10 membros da comunidade
2. Pilotar 2 rituais diferentes por 4 semanas e medir engajamento comparativo
3. Auditar coerência visual e verbal entre todos os artefatos existentes
4. Criar calendário de rituais para o próximo trimestre com owners definidos
5. Eliminar artefatos e rituais que não passam no teste de alinhamento
