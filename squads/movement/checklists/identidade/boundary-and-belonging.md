# Fronteiras e Pertencimento

## Objetivo

Definir com equilíbrio as fronteiras de pertencimento do movimento: quem está dentro,
quem está fora e como transitar entre esses estados. Fronteira frouxa demais dilui
identidade; fronteira rígida demais impede crescimento.

## Checklist

### Critérios de Pertencimento

- [ ] Existe definição clara de "membro" vs "simpatizante" vs "curioso"
- [ ] Critérios de pertencimento são baseados em ação/atitude, não em perfil demográfico
- [ ] O mínimo para pertencer está definido (qual ação = entrada no grupo)
- [ ] Existe escada de pertencimento com níveis claros (observador → participante → contribuidor → líder)
- [ ] Cada nível tem benefícios e responsabilidades proporcionais

### Mecanismos de Inclusão

- [ ] Novos membros recebem boas-vindas ativa (não são ignorados)
- [ ] Existe ritual de "primeiro ato" que marca a entrada no movimento
- [ ] Linguagem do movimento é acessível para quem está chegando (não exige conhecimento prévio)
- [ ] Barreiras de entrada são baixas mas significativas (não é grátis mas é acessível)
- [ ] Membros existentes são incentivados a acolher novatos

### Mecanismos de Fronteira

- [ ] Comportamentos que resultam em exclusão estão listados explicitamente (código de conduta)
- [ ] Existe processo justo de exclusão (aviso, conversa, decisão, comunicação)
- [ ] A fronteira protege o grupo sem ser elitista ou discriminatória
- [ ] Existe diferença clara entre "não é pra você" (legítimo) e exclusão injusta
- [ ] Membros que saem voluntariamente podem retornar com processo definido

### Senso de Pertencimento

- [ ] Membros reportam sentir-se parte de algo maior (medido por survey ou feedback)
- [ ] Existem sinais visíveis de pertencimento (badge, título, acesso especial)
- [ ] Histórias de membros são celebradas e compartilhadas regularmente
- [ ] Existe espaço para vulnerabilidade e autenticidade dentro do grupo
- [ ] O pertencimento se traduz em orgulho de associação (membros falam sobre o movimento espontaneamente)

## Critérios de Aprovação

- Todos os itens de "Critérios de Pertencimento" devem estar completos
- Todos os itens de "Mecanismos de Inclusão" devem estar completos
- Todos os itens de "Mecanismos de Fronteira" devem estar completos
- Pelo menos 4 de 5 itens de "Senso de Pertencimento" devem estar completos

## Ação se Falhar

1. Conduzir survey com membros atuais sobre percepção de pertencimento (NPS de comunidade)
2. Revisar código de conduta com contribuição da comunidade
3. Implementar programa de boas-vindas para novos membros com mentor designado
4. Criar marcos de pertencimento celebráveis (30 dias, 100 dias, 1 ano)
5. Equilibrar fronteiras com base em feedback: muito aberto ou muito fechado?
