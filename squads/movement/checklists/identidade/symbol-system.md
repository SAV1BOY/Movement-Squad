# Qualidade do Sistema de Símbolos

## Objetivo

Avaliar se o sistema de símbolos do movimento (visuais, verbais, gestuais) é forte
o suficiente para ser reconhecível, memorável e replicável. Símbolo fraco exige
explicação; símbolo forte comunica sozinho.

## Checklist

### Símbolos Visuais

- [ ] Logo/marca do movimento é reconhecível em tamanho mínimo (16x16px)
- [ ] Paleta de cores tem no máximo 5 cores com proporções de uso definidas
- [ ] Existe ícone ou gesto associado ao movimento (algo que pessoas podem replicar fisicamente)
- [ ] Sistema visual funciona em fundo claro e escuro
- [ ] Símbolos visuais são distintos de qualquer concorrente ou movimento similar

### Símbolos Verbais

- [ ] Existe slogan de no máximo 7 palavras que encapsula a tese
- [ ] Existe vocabulário proprietário do movimento (pelo menos 5 termos únicos)
- [ ] Saudação ou fechamento característico existe (como membros se cumprimentam)
- [ ] Hashtag principal do movimento é curta, memorável e não tem duplo sentido
- [ ] Storytelling de origem do movimento é contado de forma consistente

### Testabilidade e Memorabilidade

- [ ] Pessoa exposta aos símbolos 1 vez consegue descrevê-los 24h depois (teste real)
- [ ] Símbolos são desenhados para serem remixáveis (não tão rígidos que não permitam variação)
- [ ] Símbolos funcionam em pelo menos 3 formatos diferentes (digital, impresso, vídeo)
- [ ] Existe versão simplificada para uso informal (avatar, sticker, emoji customizado)
- [ ] Símbolos não têm conotação negativa não intencional em nenhuma cultura relevante

### Proteção e Governança

- [ ] Guidelines de uso dos símbolos estão documentados e acessíveis
- [ ] Existe processo para aprovar uso de símbolos por terceiros
- [ ] Registro de marca está em andamento ou completo para símbolos-chave
- [ ] Uso incorreto de símbolos tem protocolo de correção
- [ ] Evolução dos símbolos segue processo definido (não muda por capricho)

## Critérios de Aprovação

- Todos os itens de "Símbolos Visuais" devem estar completos
- Pelo menos 4 de 5 itens de "Símbolos Verbais" devem estar completos
- Pelo menos 4 de 5 itens de "Testabilidade" devem estar completos
- Pelo menos 4 de 5 itens de "Proteção e Governança" devem estar completos

## Ação se Falhar

1. Realizar teste de memorabilidade com 20 pessoas externas ao movimento
2. Contratar/consultar designer especialista em identidade de movimento
3. Simplificar símbolos que não passam no teste de reconhecimento rápido
4. Criar brand book mínimo viável (5 páginas) com regras de uso
5. Implementar revisão de símbolos como parte da auditoria trimestral de identidade
