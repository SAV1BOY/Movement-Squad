# Definição de Identidade Nós/Eles/Agora

## Objetivo

Definir com clareza quem é o "nós" (in-group), quem é o "eles" (out-group ou status quo)
e por que "agora" é o momento. Essa tríade é o motor emocional de todo movimento —
sem ela, não há urgência nem união.

## Checklist

### Definição do "Nós"

- [ ] O "nós" está descrito em 1 parágrafo que gera identificação imediata
- [ ] Características compartilhadas do grupo estão listadas (valores, comportamentos, crenças)
- [ ] O "nós" é inclusivo o suficiente para crescer mas exclusivo o suficiente para ter identidade
- [ ] Existe frase que um membro diria para se identificar ("eu sou alguém que...")
- [ ] O "nós" não depende de dados demográficos mas de atitude/mentalidade

### Definição do "Eles"

- [ ] O "eles" é um sistema, mentalidade ou prática — nunca um grupo de pessoas
- [ ] A oposição é clara sem ser odiosa (antagonismo produtivo, não destrutivo)
- [ ] O status quo que o movimento desafia está descrito concretamente
- [ ] Existe diferenciação entre "eles" e "adversário" (não é guerra, é transformação)
- [ ] A narrativa do "eles" não é demonizante — é questionadora

### Definição do "Agora"

- [ ] O motivo de urgência está articulado com dados ou tendência observável
- [ ] Existe um catalisador externo que torna o momento oportuno (evento, mudança, crise)
- [ ] A consequência de não agir agora está descrita (o que se perde com inação)
- [ ] O "agora" é renovável (não depende de um único momento que passa)
- [ ] A urgência é genuína, não manufaturada (passa no teste de honestidade)

### Integração da Tríade

- [ ] As três dimensões se conectam em uma narrativa coerente de 3 parágrafos
- [ ] O manifesto do movimento reflete a tríade explicitamente
- [ ] Membros da comunidade conseguem articular a tríade em suas próprias palavras
- [ ] A tríade é revisada trimestralmente para garantir relevância contínua
- [ ] Novos membros recebem a tríade como parte do onboarding

## Critérios de Aprovação

- Todos os itens de "Definição do Nós" devem estar completos
- Todos os itens de "Definição do Eles" devem estar completos
- Todos os itens de "Definição do Agora" devem estar completos
- Todos os itens de "Integração da Tríade" devem estar completos

## Ação se Falhar

1. Workshop de identidade com equipe + 5 membros da comunidade (3 horas)
2. Testar 3 versões da tríade com público-alvo e medir identificação
3. Revisar movimentos históricos bem-sucedidos para extrair padrões de tríade
4. Refinar narrativa até conseguir articular em 30 segundos (elevator pitch)
5. Documentar versão final e disseminar para toda a equipe com treinamento
