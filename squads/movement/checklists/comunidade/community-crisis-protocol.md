# Protocolo de Crise Comunitária

## Objetivo

Garantir que a comunidade tem protocolo de crise pronto para ser ativado quando
eventos disruptivos acontecem (conflito interno, crise de marca, brigading externo,
tragédia). Crise sem protocolo transforma problema em catástrofe.

## Checklist

### Classificação de Crise

- [ ] Tipos de crise estão catalogados: conflito entre membros, crise de marca, ataque externo, vazamento, tragédia
- [ ] Cada tipo tem nível de severidade: 1 (baixo, resolução local) a 5 (crítico, resposta institucional)
- [ ] Critérios de escalação por nível estão documentados (quem aciona, quem decide)
- [ ] Existe diferenciação entre incidente (pontual) e crise (sistêmico/em escala)
- [ ] Exemplos de cada tipo de crise com resposta recomendada estão documentados

### Equipe de Resposta

- [ ] War room (canal de comunicação de crise) está configurado e testado
- [ ] Roles de crise estão definidos: decisor, comunicador, monitor, suporte
- [ ] Lista de contatos de emergência está atualizada (moderadores, legal, PR, chief)
- [ ] Substitutos para cada role estão nomeados (se titular não estiver disponível)
- [ ] Equipe de resposta fez simulação de crise nos últimos 90 dias

### Protocolo de Comunicação

- [ ] Template de primeira comunicação ("estamos cientes, estamos agindo") está pronto
- [ ] Cadência de atualizações durante crise está definida (a cada 2h para crise nível 4-5)
- [ ] Canais de comunicação durante crise estão priorizados (qual plataforma usar)
- [ ] Linguagem de crise é direta, honesta e empática (sem corporativês ou evasão)
- [ ] Comunicação interna (equipe) acontece antes da comunicação externa (comunidade)

### Pós-Crise

- [ ] Retrospectiva de crise é realizada em até 72h após resolução
- [ ] Comunicado final com resolução e aprendizados é publicado para comunidade
- [ ] Membros afetados recebem acompanhamento individual (se aplicável)
- [ ] Protocolo é atualizado com aprendizados da crise real
- [ ] Monitoramento reforçado é mantido por 2 semanas após crise (risco de recidiva)

## Critérios de Aprovação

- Todos os itens de "Classificação" devem estar completos
- Todos os itens de "Equipe de Resposta" devem estar completos
- Todos os itens de "Protocolo de Comunicação" devem estar completos
- Todos os itens de "Pós-Crise" devem estar completos

## Ação se Falhar

1. URGENTE: criar protocolo mínimo de crise em 24 horas (classificação + roles + template)
2. Configurar canal de war room e testar com equipe
3. Realizar primeira simulação de crise (cenário: membro influente critica publicamente o movimento)
4. Preparar 3 templates de comunicação de crise para cenários mais prováveis
5. Agendar simulação trimestral de crise como ritual obrigatório da equipe
