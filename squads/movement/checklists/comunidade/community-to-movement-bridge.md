# Ponte Comunidade → Movimento

## Objetivo

Garantir que a comunidade não é apenas um grupo de pessoas reunidas, mas que
existe ponte clara que transforma membros de comunidade em agentes do movimento.
Comunidade sem ponte é grupo de interesse; com ponte, é força de transformação.

## Checklist

### Consciência de Causa

- [ ] Membros entendem que fazem parte de algo maior que um grupo (tese do movimento é conhecida)
- [ ] Pelo menos 50% dos membros ativos conseguem articular a tese em suas palavras
- [ ] Conteúdo educativo sobre a causa do movimento é oferecido regularmente (não apenas produto)
- [ ] Histórias de impacto real (como o movimento fez diferença) são compartilhadas mensalmente
- [ ] A conexão entre participar da comunidade e contribuir para mudança está explícita

### Ações de Movimento

- [ ] Existem pelo menos 3 ações concretas que membros podem fazer para avançar a causa
- [ ] Ações variam em nível de compromisso (compartilhar = fácil, criar = médio, liderar = difícil)
- [ ] Cada ação tem impacto mensurável e reportado à comunidade
- [ ] Membros que realizam ações são reconhecidos publicamente
- [ ] Ações são co-criadas com a comunidade (não impostas de cima para baixo)

### Transformação Pessoal

- [ ] Membros reportam mudança de comportamento ou perspectiva desde que entraram
- [ ] Testemunhos de transformação são coletados e amplificados sistematicamente
- [ ] A comunidade oferece suporte para membros implementarem mudanças em suas vidas
- [ ] Existe framework de "progresso pessoal" dentro do movimento (onde comecei → onde estou)
- [ ] Membros transformados se tornam os melhores recrutadores naturais do movimento

### Impacto Coletivo

- [ ] Existe pelo menos 1 objetivo coletivo que toda a comunidade persegue junto
- [ ] Progresso em direção ao objetivo coletivo é visível e atualizado regularmente
- [ ] Contribuição individual para o objetivo coletivo é rastreável (meu papel no todo)
- [ ] Marcos coletivos são celebrados com a comunidade toda (não só pela equipe)
- [ ] O impacto coletivo é comunicado externamente para atrair novos membros

## Critérios de Aprovação

- Todos os itens de "Consciência de Causa" devem estar completos
- Todos os itens de "Ações de Movimento" devem estar completos
- Pelo menos 4 de 5 itens de "Transformação Pessoal" devem estar completos
- Pelo menos 4 de 5 itens de "Impacto Coletivo" devem estar completos

## Ação se Falhar

1. Reforçar narrativa do movimento na comunicação comunitária (lembrar o "por quê")
2. Criar pelo menos 1 ação coletiva tangível para o próximo mês
3. Coletar 5 histórias de transformação de membros e compartilhar na comunidade
4. Definir objetivo coletivo com a comunidade e criar dashboard de progresso
5. Implementar ritual mensal de "impacto" onde a comunidade vê o efeito coletivo
