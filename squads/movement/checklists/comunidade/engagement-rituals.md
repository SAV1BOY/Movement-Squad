# Qualidade dos Rituais de Engajamento

## Objetivo

Avaliar se os rituais de engajamento da comunidade geram participação recorrente,
conexão entre membros e senso de pertencimento. Ritual bem desenhado cria hábito;
ritual genérico gera obrigação e eventualmente abandono.

## Checklist

### Inventário de Rituais

- [ ] Pelo menos 3 rituais recorrentes estão ativos (frequências: diário, semanal, mensal)
- [ ] Cada ritual tem nome próprio reconhecível pela comunidade
- [ ] Cada ritual tem duração definida (início e fim claros — não se arrasta)
- [ ] Cada ritual tem formato documentado (quem lidera, como participa, o que produz)
- [ ] Rituais cobrem diferentes tipos de engajamento (aprender, discutir, criar, celebrar)

### Participação e Adesão

- [ ] Taxa de participação de cada ritual é medida (% de membros ativos que participam)
- [ ] Tendência de participação é monitorada (crescendo, estável ou declinando)
- [ ] Ritual com participação < 10% dos membros ativos por 3 edições é revisado
- [ ] Novos membros participam de pelo menos 1 ritual nos primeiros 14 dias
- [ ] Participação não depende de incentivo externo (prêmio, sorteio) para acontecer

### Qualidade da Experiência

- [ ] Participantes reportam valor ao final do ritual (survey ou feedback informal)
- [ ] Rituais geram conexão entre membros (não apenas com a marca/equipe)
- [ ] Output dos rituais é visível (post, resumo, artefato) para não-participantes
- [ ] Rituais são acessíveis em termos de horário, formato e barreira de participação
- [ ] Existe momento de "delight" (surpresa positiva) em pelo menos 1 ritual

### Evolução dos Rituais

- [ ] Feedback de participantes é coletado após cada edição dos rituais-chave
- [ ] Novos rituais são testados em formato piloto (3 edições) antes de oficializar
- [ ] Rituais que não geram valor são aposentados com comunicação honesta à comunidade
- [ ] A comunidade pode propor novos rituais com processo simples
- [ ] Revisão trimestral de rituais é feita com dados de participação e feedback

## Critérios de Aprovação

- Todos os itens de "Inventário de Rituais" devem estar completos
- Pelo menos 4 de 5 itens de "Participação" devem estar completos
- Pelo menos 4 de 5 itens de "Qualidade da Experiência" devem estar completos
- Todos os itens de "Evolução" devem estar completos

## Ação se Falhar

1. Criar 1 ritual semanal simples e executar 4 edições consecutivas como piloto
2. Observar comunidades de referência para inspiração de rituais que funcionam
3. Envolver membros veteranos na co-criação e facilitação de rituais
4. Medir NPS de cada ritual para priorizar investimento nos mais valorizados
5. Documentar playbook de cada ritual para que qualquer pessoa da equipe possa facilitar
