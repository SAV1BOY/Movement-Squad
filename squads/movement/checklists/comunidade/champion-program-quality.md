# Qualidade do Programa de Champions

## Objetivo

Avaliar se o programa de champions (embaixadores/líderes comunitários) está gerando
multiplicadores reais do movimento, não apenas coletores de benefícios. Champion bom
gera mais champions; programa ruim gera dependência.

## Checklist

### Seleção de Champions

- [ ] Critérios de seleção estão documentados (engajamento, alinhamento, influência)
- [ ] Seleção é baseada em comportamento observado (não em auto-candidatura apenas)
- [ ] Processo seletivo inclui entrevista ou conversa 1:1 (não é automático)
- [ ] Diversidade de perfis é buscada ativamente na seleção
- [ ] Número de champions é proporcional ao tamanho da comunidade (1 para cada 50-100 membros)

### Capacitação e Suporte

- [ ] Onboarding do champion tem treinamento específico (tom de voz, regras, ferramentas)
- [ ] Champions têm acesso a informações exclusivas (roadmap, bastidores, dados)
- [ ] Existe canal de suporte exclusivo para champions resolverem dúvidas rapidamente
- [ ] Champions recebem feedback sobre sua atuação pelo menos mensalmente
- [ ] Material de apoio (templates, scripts, FAQs) é fornecido e atualizado

### Benefícios e Reconhecimento

- [ ] Champions têm benefícios tangíveis proporcionais ao esforço (acesso, produtos, experiências)
- [ ] Reconhecimento público é dado regularmente (destaque em canais, menções, badges)
- [ ] Benefícios são sustentáveis para a empresa a longo prazo (não promessas infladas)
- [ ] Existe progressão dentro do programa (champion → senior champion → advisor)
- [ ] Champions que se destacam têm oportunidades reais (trabalho, parcerias, co-criação)

### Impacto e Mensuração

- [ ] Cada champion tem métricas de contribuição rastreadas (posts, eventos, indicações)
- [ ] Impacto coletivo do programa é reportado mensalmente (members adquiridos, engajamento gerado)
- [ ] Champions inativos > 30 dias recebem check-in e possível redesignação
- [ ] NPS do programa entre champions é medido trimestralmente (eles estão satisfeitos?)
- [ ] ROI do programa (custo dos benefícios vs valor gerado) é calculado semestralmente

## Critérios de Aprovação

- Todos os itens de "Seleção" devem estar completos
- Todos os itens de "Capacitação" devem estar completos
- Pelo menos 4 de 5 itens de "Benefícios" devem estar completos
- Todos os itens de "Impacto" devem estar completos

## Ação se Falhar

1. Definir critérios de seleção se não existem e fazer primeira seleção com 5-10 champions
2. Criar kit de onboarding do champion com tudo que precisa saber em 1 documento
3. Implementar tracking mínimo de contribuição por champion
4. Agendar reunião mensal com champions para alinhamento e feedback bilateral
5. Pesquisar programas de referência no mercado para calibrar benefícios e expectativas
