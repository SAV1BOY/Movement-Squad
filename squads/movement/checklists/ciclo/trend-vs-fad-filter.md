# Filtro de Tendência vs Modismo

## Objetivo

Diferenciar tendências duradouras (que merecem investimento estratégico) de modismos
passageiros (que merecem no máximo tática oportunista). Investir pesado em modismo é
desperdício; ignorar tendência é negligência estratégica.

## Checklist

### Sinais de Tendência (Durável)

- [ ] O fenômeno existe há mais de 6 meses e ainda está crescendo
- [ ] Adoção está acontecendo em múltiplos segmentos demográficos (não apenas early adopters)
- [ ] Existem mudanças estruturais que sustentam o fenômeno (tecnologia, regulação, cultura)
- [ ] Empresas estabelecidas estão investindo no tema (não apenas startups e influenciadores)
- [ ] O fenômeno resolve um problema real que não vai desaparecer

### Sinais de Modismo (Passageiro)

- [ ] O crescimento foi explosivo mas iniciou há menos de 3 meses
- [ ] Engajamento é concentrado em 1 plataforma ou 1 formato específico
- [ ] Não existe fundamentação estrutural — é baseado em novidade ou curiosidade
- [ ] Os principais promotores são criadores de conteúdo buscando views (não especialistas)
- [ ] O público trata como entretenimento, não como mudança de comportamento

### Critérios de Decisão

- [ ] Cada novo tema é avaliado no framework tendência vs modismo antes de investimento
- [ ] Investimento em tendência: estratégico (conteúdo profundo, posicionamento, comunidade)
- [ ] Investimento em modismo: tático (1-3 peças de conteúdo reativo, máximo 48h de produção)
- [ ] Existe teto de investimento para modismo (< 5% do budget mensal)
- [ ] Decisão é documentada com data para revisão futura (calibrar aprendizado)

### Monitoramento e Revisão

- [ ] Temas classificados como tendência são monitorados mensalmente para confirmar
- [ ] Modismos que persistem > 6 meses são reclassificados como tendência potencial
- [ ] Tendências que desaceleraram são reclassificadas com ajuste de investimento
- [ ] Acurácia das classificações anteriores é medida trimestralmente (aprendizado)
- [ ] Equipe tem acesso a fontes de dados para fundamentar classificação (não é "achismo")

## Critérios de Aprovação

- Pelo menos 4 de 5 itens de "Sinais de Tendência" devem ser verificáveis
- Pelo menos 4 de 5 itens de "Sinais de Modismo" devem ser verificáveis
- Todos os itens de "Critérios de Decisão" devem estar completos
- Todos os itens de "Monitoramento e Revisão" devem estar completos

## Ação se Falhar

1. Criar base de dados de temas com classificação e data para tracking longitudinal
2. Definir fontes de dados primárias para avaliação (Google Trends, social volume, pesquisas)
3. Treinar equipe no framework de classificação com casos reais
4. Revisar investimentos passados em modismos para quantificar desperdício
5. Implementar gate obrigatório de classificação antes de qualquer investimento em tema novo
