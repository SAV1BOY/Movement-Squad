# Sazonalidade e Alinhamento com Eventos

## Objetivo

Garantir que o movimento aproveita sazonalidade e eventos externos de forma
estratégica, sem parecer oportunista forçado. O calendário cultural é acelerador
de relevância — quando bem usado.

## Checklist

### Mapeamento Sazonal

- [ ] Calendário anual de datas relevantes para o movimento está documentado
- [ ] Cada data tem classificação: obrigatória, oportuna ou irrelevante
- [ ] Histórico de performance do movimento por período sazonal está analisado
- [ ] Períodos de alta e baixa atenção do público estão mapeados
- [ ] Sazonalidade financeira do público está considerada (13o, Black Friday, início de ano)

### Eventos Externos

- [ ] Eventos do setor (conferências, feiras, lançamentos) estão no radar com 90 dias de antecedência
- [ ] Eventos culturais (shows, filmes, séries, virais) são monitorados para oportunidades
- [ ] Existe protocolo de avaliação rápida: "devemos nos associar a este evento?"
- [ ] Critérios de associação estão claros (alinhamento com tese, risco reputacional, ROI estimado)
- [ ] Lead time de produção para cada tipo de evento está calculado

### Planejamento de Conteúdo Sazonal

- [ ] Conteúdo sazonal é planejado com mínimo 30 dias de antecedência
- [ ] Cada ação sazonal tem objetivo específico (não é "postar porque todo mundo posta")
- [ ] Existe versão "sempre pronta" para eventos previsíveis anuais (templates reutilizáveis)
- [ ] Conteúdo sazonal mantém identidade do movimento (não é genérico de data comemorativa)
- [ ] Budget extra para ações sazonais está previsto no orçamento

### Oportunismo Planejado

- [ ] Equipe tem autonomia e processo para reagir a eventos em < 24h (real-time marketing)
- [ ] Existe checklist rápido de aprovação para conteúdo reativo (risco x oportunidade)
- [ ] Pelo menos 3 "cenários previsíveis" têm conteúdo pré-preparado
- [ ] Performance de ações reativas vs planejadas é comparada trimestralmente
- [ ] Existe política clara de quando NÃO reagir a um evento (às vezes silêncio é estratégico)

## Critérios de Aprovação

- Todos os itens de "Mapeamento Sazonal" devem estar completos
- Pelo menos 4 de 5 itens de "Eventos Externos" devem estar completos
- Todos os itens de "Planejamento de Conteúdo Sazonal" devem estar completos
- Pelo menos 4 de 5 itens de "Oportunismo Planejado" devem estar completos

## Ação se Falhar

1. Criar calendário anual de sazonalidade em sessão dedicada com equipe
2. Preparar 5 templates reutilizáveis para datas obrigatórias do ano
3. Definir processo de aprovação rápida para conteúdo reativo (< 2h)
4. Analisar competidores para identificar oportunidades sazonais perdidas
5. Reservar 20% do budget trimestral para ações sazonais e oportunistas
