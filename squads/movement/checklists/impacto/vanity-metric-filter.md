# Filtro de Métricas de Vaidade

## Objetivo

Identificar e neutralizar métricas de vaidade que inflam percepção de sucesso
sem refletir impacto real. Métrica de vaidade é anestésico organizacional —
faz sentir bem enquanto o movimento pode estar morrendo.

## Checklist

### Identificação de Métricas de Vaidade

- [ ] Lista de todas as métricas reportadas está documentada
- [ ] Cada métrica passou pelo teste: "se esse número dobrar, o que muda na prática?"
- [ ] Métricas que não passam no teste estão sinalizadas como potencial vaidade
- [ ] Seguidores/likes/impressões são tratados como input, não como resultado
- [ ] Métricas de volume sem taxa (ex: "1000 views" sem "% de retenção") estão identificadas

### Substituição por Métricas Reais

- [ ] Para cada métrica de vaidade, existe métrica substituta que mede impacto real
- [ ] "Seguidores" é complementado por "taxa de engajamento ativo" (comentar, compartilhar, criar)
- [ ] "Impressões" é complementado por "taxa de clique" e "taxa de conversão"
- [ ] "Membros da comunidade" é complementado por "membros ativos semanalmente"
- [ ] "Crescimento total" é complementado por "crescimento de cohort retido > 30 dias"

### Comunicação Honesta

- [ ] Reports para stakeholders priorizam métricas de impacto real sobre vaidade
- [ ] Quando métricas de vaidade são apresentadas, sempre acompanhadas de métrica real
- [ ] Equipe está treinada para questionar métricas de vaidade em reuniões
- [ ] Celebrações são baseadas em métricas reais (não em número bonito de seguidores)
- [ ] Dashboard principal mostra métricas reais em destaque, vaidade em segundo plano

### Disciplina Contínua

- [ ] Revisão de "é vaidade?" é feita em toda nova métrica proposta para tracking
- [ ] Pelo menos 1 métrica de vaidade foi removida de reports nos últimos 90 dias
- [ ] A equipe consegue explicar por que cada métrica no dashboard importa para o negócio
- [ ] Existe provocação mensal: "e se esse número fosse zero, o que mudaria?"
- [ ] Stakeholders foram educados sobre diferença entre vaidade e impacto

## Critérios de Aprovação

- Todos os itens de "Identificação" devem estar completos
- Todos os itens de "Substituição" devem estar completos
- Pelo menos 4 de 5 itens de "Comunicação Honesta" devem estar completos
- Pelo menos 4 de 5 itens de "Disciplina Contínua" devem estar completos

## Ação se Falhar

1. Auditar dashboard atual marcando cada métrica como "impacto real" ou "vaidade"
2. Para cada vaidade, definir substituta real com fórmula e fonte de dados
3. Refazer template de report com métricas reais em destaque
4. Treinar equipe com exemplos concretos de vaidade vs impacto do próprio movimento
5. Implementar gate: toda nova métrica precisa justificar "qual decisão isso influencia?"
