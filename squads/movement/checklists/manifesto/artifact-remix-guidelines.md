# Guidelines de Remix de Artefatos

## Objetivo

Definir regras claras sobre como a comunidade e parceiros podem remixar artefatos
do movimento sem descaracterizar a identidade. Remix é a alma da viralidade — mas
remix sem regras é descontrole.

## Checklist

### Permissões de Remix

- [ ] Está claro quais artefatos são "abertos" para remix (texto, imagem, template)
- [ ] Está claro quais artefatos são "fechados" (logo, elementos core de identidade)
- [ ] Licença de uso está definida (Creative Commons, proprietária com permissão, etc.)
- [ ] Membros da comunidade sabem onde encontrar artefatos remixáveis (repositório acessível)
- [ ] Processo de solicitação para uso especial (fora das permissões padrão) existe

### Limites de Remix

- [ ] Elementos que NÃO podem ser alterados estão listados (cores primárias, logo, slogan)
- [ ] Contextos proibidos de uso estão documentados (conteúdo político, adulto, comercial sem aprovação)
- [ ] Deformação de proporção do logo é explicitamente proibida
- [ ] Associação com marcas/causas sem aprovação é proibida
- [ ] Exemplos visuais de "remix aceitável" vs "remix inaceitável" estão documentados

### Incentivo ao Remix

- [ ] Templates editáveis (Canva, Figma, PSD) estão disponíveis para download
- [ ] Existe galeria de "melhores remixes" para inspirar e reconhecer a comunidade
- [ ] Remixes de destaque são compartilhados nos canais oficiais (crédito ao autor)
- [ ] Desafios de remix são realizados periodicamente para estimular criação
- [ ] Não existe barreira técnica para remix (formatos acessíveis, ferramentas gratuitas)

### Moderação de Remixes

- [ ] Existe processo de monitoramento de remixes em circulação (social listening)
- [ ] Remixes que violam guidelines recebem comunicação educativa (não punitiva) em 48h
- [ ] Remixes que causam dano reputacional são endereçados com urgência (< 24h)
- [ ] Existe contato claro para denúncia de uso indevido de artefatos
- [ ] Registro de incidentes de uso indevido é mantido para identificar padrões

## Critérios de Aprovação

- Todos os itens de "Permissões" devem estar completos
- Todos os itens de "Limites" devem estar completos
- Pelo menos 4 de 5 itens de "Incentivo" devem estar completos
- Todos os itens de "Moderação" devem estar completos

## Ação se Falhar

1. Criar documento de guidelines de remix com exemplos visuais (do vs don't)
2. Disponibilizar templates editáveis em plataforma acessível (Canva, Figma)
3. Comunicar guidelines à comunidade com post educativo (não como regra restritiva)
4. Implementar monitoramento de uso de artefatos via busca reversa de imagem
5. Revisar guidelines semestralmente com base em incidentes e feedback da comunidade
