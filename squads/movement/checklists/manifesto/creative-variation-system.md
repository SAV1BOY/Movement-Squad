# Sistema de Variação Criativa

## Objetivo

Garantir que o movimento produz variação criativa suficiente para evitar monotonia
sem perder coerência de identidade. Conteúdo repetitivo mata engajamento;
conteúdo aleatório mata reconhecimento.

## Checklist

### Matriz de Variação

- [ ] Pelo menos 5 formatos diferentes de conteúdo estão em uso ativo (texto, vídeo, imagem, áudio, interativo)
- [ ] Cada formato tem pelo menos 3 sub-formatos (ex: vídeo curto, longo, live, behind-the-scenes)
- [ ] Proporção entre formatos está definida (ex: 40% vídeo, 30% imagem, 20% texto, 10% áudio)
- [ ] Rotação de formatos é intencional (não publicar o mesmo formato 5 vezes seguidas)
- [ ] Calendário editorial reflete diversidade de formato visualmente

### Sistema de Pilares de Conteúdo

- [ ] Existem 3-5 pilares de conteúdo definidos (ex: educação, inspiração, comunidade, bastidores)
- [ ] Cada pilar tem proporção de uso definida no calendário (ex: 30%, 25%, 25%, 20%)
- [ ] Cada pilar tem exemplos de referência documentados para orientar a equipe
- [ ] Pilares cobrem diferentes momentos emocionais (nem tudo é hype; precisa de profundidade também)
- [ ] Pilares são revisados trimestralmente para ajustar ao momento do movimento

### Processo de Criação

- [ ] Briefing criativo tem template padronizado que garante variação intencional
- [ ] Existe sessão de brainstorm mensal para gerar estoque de ideias por pilar
- [ ] Cada peça de conteúdo é avaliada contra: "o que há de diferente em relação às últimas 5?"
- [ ] Colaboradores externos (designers, copywriters, creators) trazem perspectiva fresca regularmente
- [ ] Existe banco de ideias sempre alimentado com pelo menos 20 ideias não executadas

### Anti-Monotonia

- [ ] Auditoria mensal verifica que nenhum formato representa > 60% do total publicado
- [ ] Nenhum pilar de conteúdo fica sem publicação por mais de 2 semanas
- [ ] Conteúdo "coringa" (fora dos pilares, experimental) representa 5-10% do total
- [ ] Feedback de monotonia da comunidade é monitorado e endereçado em até 1 semana
- [ ] Teste A/B de formatos é realizado pelo menos mensalmente

## Critérios de Aprovação

- Todos os itens de "Matriz de Variação" devem estar completos
- Todos os itens de "Sistema de Pilares" devem estar completos
- Pelo menos 4 de 5 itens de "Processo de Criação" devem estar completos
- Pelo menos 4 de 5 itens de "Anti-Monotonia" devem estar completos

## Ação se Falhar

1. Auditar últimas 30 publicações por formato e pilar para diagnosticar monotonia
2. Criar ou atualizar matriz de variação com proporções por formato e pilar
3. Alimentar banco de ideias com sessão de brainstorm de 2 horas
4. Introduzir pelo menos 1 formato novo por mês como experimento
5. Implementar revisão de variação como gate obrigatório no calendário editorial
