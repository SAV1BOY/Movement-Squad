# Verificação de Vida Útil dos Artefatos

## Objetivo

Avaliar se cada artefato do movimento ainda está relevante, atualizado e eficaz.
Artefato desatualizado circulando é pior que artefato faltando — comunica
desleixo e erode confiança.

## Checklist

### Classificação de Vida Útil

- [ ] Cada artefato tem classificação: evergreen (sem prazo) ou temporal (com validade)
- [ ] Artefatos temporais têm data de expiração documentada
- [ ] Artefatos evergreen têm data de revisão obrigatória (mínimo trimestral)
- [ ] Existe inventário completo de todos os artefatos em circulação
- [ ] Cada artefato tem versão e data de última atualização registradas

### Verificação de Relevância

- [ ] Dados e estatísticas citados em artefatos ainda são atuais (não outdated)
- [ ] Referências culturais ainda são relevantes (meme de 6 meses atrás pode ser cringe)
- [ ] Screenshots e exemplos visuais refletem versão atual do produto/plataforma
- [ ] Linguagem e tom ainda estão alinhados com versão atual da identidade
- [ ] Links e URLs em artefatos estão funcionando (não há links quebrados)

### Verificação de Performance

- [ ] Cada artefato tem pelo menos 1 métrica de performance associada
- [ ] Artefatos com engajamento < 50% da média são sinalizados para revisão ou aposentadoria
- [ ] Artefatos com alto engajamento são priorizados para atualização (manter relevantes)
- [ ] A/B tests de versões atualizadas vs originais são realizados quando possível
- [ ] Top 10 artefatos por performance são identificados e amplificados

### Processo de Aposentadoria

- [ ] Artefatos expirados são removidos de circulação ativa (não apenas ignorados)
- [ ] Artefatos aposentados são arquivados (não deletados) com nota de obsolescência
- [ ] Substituição é produzida antes ou simultaneamente à aposentadoria
- [ ] Comunidade é avisada quando artefatos populares são descontinuados
- [ ] Revisão de vida útil é realizada mensalmente com inventário atualizado

## Critérios de Aprovação

- Todos os itens de "Classificação" devem estar completos
- Todos os itens de "Verificação de Relevância" devem estar completos
- Pelo menos 4 de 5 itens de "Performance" devem estar completos
- Todos os itens de "Processo de Aposentadoria" devem estar completos

## Ação se Falhar

1. Criar inventário completo de artefatos em planilha com versão, data e classificação
2. Auditar todos os artefatos em circulação contra checklist de relevância
3. Remover ou atualizar imediatamente artefatos com dados desatualizados
4. Estabelecer alerta automático para artefatos próximos da data de revisão
5. Designar responsável por manutenção de cada artefato (não é tarefa de todos = tarefa de ninguém)
