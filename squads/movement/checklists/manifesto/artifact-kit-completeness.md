# Completude do Kit de Artefatos

## Objetivo

Verificar que o kit de artefatos do movimento está completo e pronto para uso
em todos os cenários necessários. Kit incompleto gera improvisação, e
improvisação gera inconsistência.

## Checklist

### Artefatos Textuais

- [ ] Manifesto em versão completa (500-1000 palavras) está finalizado e aprovado
- [ ] Manifesto em versão curta (100-150 palavras) para redes sociais está pronto
- [ ] Bio/descrição padronizada para cada plataforma (Instagram, LinkedIn, Twitter, TikTok)
- [ ] FAQ do movimento com pelo menos 15 perguntas e respostas está documentado
- [ ] Email de boas-vindas para novos membros está escrito e configurado

### Artefatos Visuais

- [ ] Logo em formatos PNG (transparente), SVG e JPG em alta resolução
- [ ] Variações de logo: horizontal, vertical, ícone, monocromático
- [ ] Templates de post para cada rede social (feed, story, carrossel)
- [ ] Paleta de cores com códigos hex, RGB e CMYK documentados
- [ ] Tipografia definida com fontes primária e secundária e links de download

### Artefatos de Compartilhamento

- [ ] Wallpapers para desktop e mobile com identidade do movimento
- [ ] Stickers digitais (mínimo 10) para uso em mensageiros e stories
- [ ] Templates para membros criarem próprio conteúdo (editáveis em Canva ou similar)
- [ ] Badge/selo de membro para uso em perfis pessoais
- [ ] Kit de mídia para imprensa com logo, fotos, bio e key messages

### Artefatos de Experiência

- [ ] Deck de apresentação do movimento (10-15 slides) para pitch e parcerias
- [ ] Guia de onboarding para novos membros (formato digital, max 5 min de leitura)
- [ ] Playlist ou trilha sonora do movimento (se aplicável à identidade)
- [ ] Template de convite para eventos do movimento
- [ ] Glossário do movimento com termos-chave e definições

## Critérios de Aprovação

- Todos os itens de "Artefatos Textuais" devem estar completos
- Todos os itens de "Artefatos Visuais" devem estar completos
- Pelo menos 4 de 5 itens de "Artefatos de Compartilhamento" devem estar completos
- Pelo menos 4 de 5 itens de "Artefatos de Experiência" devem estar completos

## Ação se Falhar

1. Listar artefatos faltantes por prioridade (o que bloqueia lançamento vs nice to have)
2. Produzir artefatos P0 em sprint de 1 semana com equipe focada
3. Para artefatos que precisam de especialista, contratar freelancer com briefing claro
4. Centralizar todos os artefatos em pasta acessível com nomenclatura padronizada
5. Criar checklist de QA para cada artefato (resolução, cores, textos, links)
