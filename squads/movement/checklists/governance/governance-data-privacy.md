# Privacidade de Dados e Consentimento

## Objetivo

Verificar que o movimento trata dados pessoais dos membros e público com rigor,
transparência e conformidade legal. Confiança é o ativo mais valioso de um
movimento — e violação de privacidade destrói confiança irreversivelmente.

## Checklist

### Inventário de Dados

- [ ] Todos os tipos de dados pessoais coletados estão catalogados (nome, email, IP, comportamento)
- [ ] Para cada dado, a finalidade de coleta está documentada (por que coletamos isso?)
- [ ] Para cada dado, o período de retenção está definido (por quanto tempo guardamos?)
- [ ] Dados desnecessários para a operação foram identificados e descartados (minimização)
- [ ] Fluxo de dados entre ferramentas e sistemas está mapeado (de onde para onde dados trafegam)

### Consentimento

- [ ] Consentimento é coletado de forma explícita antes de qualquer tratamento de dados
- [ ] O texto do consentimento é claro e em linguagem acessível (não juridiquês incompreensível)
- [ ] Opt-in é ativo (checkbox desmarcado por padrão — nunca pré-marcado)
- [ ] Consentimento para diferentes finalidades é separado (newsletter ≠ compartilhar com parceiro)
- [ ] Retirada de consentimento é tão fácil quanto o fornecimento (unsubscribe funcional)

### Segurança dos Dados

- [ ] Dados pessoais estão armazenados em plataformas com padrão mínimo de segurança (encriptação)
- [ ] Acesso a dados é restrito por necessidade (nem toda a equipe acessa tudo)
- [ ] Compartilhamento de dados com terceiros tem contrato de processamento de dados (DPA)
- [ ] Backup de dados pessoais está protegido com mesmos padrões do dado principal
- [ ] Política de resposta a vazamento de dados existe com timeline e ações definidas

### Direitos dos Titulares

- [ ] Membros podem acessar seus dados pessoais mediante solicitação (prazo < 15 dias)
- [ ] Membros podem solicitar exclusão de seus dados (direito ao esquecimento)
- [ ] Membros podem solicitar portabilidade de seus dados
- [ ] Canal de solicitação de direitos é visível e funcional
- [ ] Registros de solicitações atendidas são mantidos como prova de compliance

### Governança de Privacidade

- [ ] Privacy Impact Assessment (PIA) é realizado antes de nova coleta ou uso de dados
- [ ] Treinamento de privacidade é oferecido à equipe anualmente
- [ ] Incidentes de privacidade são reportados e investigados em até 72 horas
- [ ] Política de privacidade é revisada semestralmente e atualizada quando necessário
- [ ] Fornecedores de tecnologia são avaliados quanto a práticas de privacidade

## Critérios de Aprovação

- Todos os itens de "Inventário de Dados" devem estar completos
- Todos os itens de "Consentimento" devem estar completos
- Todos os itens de "Segurança dos Dados" devem estar completos
- Todos os itens de "Direitos dos Titulares" devem estar completos
- Pelo menos 4 de 5 itens de "Governança de Privacidade" devem estar completos

## Ação se Falhar

1. URGENTE: verificar se existe violação ativa de LGPD e corrigir imediatamente
2. Criar inventário de dados pessoais coletados com finalidade e base legal
3. Revisar e atualizar textos de consentimento em todos os pontos de coleta
4. Implementar canal de solicitação de direitos dos titulares funcional
5. Contratar consultoria de privacidade para audit completo se gaps forem significativos
