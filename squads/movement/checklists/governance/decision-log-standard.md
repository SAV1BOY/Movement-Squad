# Padrão de Registro de Decisões

## Objetivo

Garantir que todas as decisões significativas do movimento são registradas com
contexto, justificativa e responsável. Decision log é a memória institucional que
previne repetição de erros e permite accountability real.

## Checklist

### Estrutura do Registro

- [ ] Template de decision log está definido e acessível (data, decisor, contexto, opções, escolha, justificativa)
- [ ] Cada decisão tem identificador único para referência futura
- [ ] O contexto (por que a decisão era necessária) está documentado em cada registro
- [ ] As alternativas consideradas estão listadas (não apenas a decisão final)
- [ ] A justificativa para a escolha feita está articulada (dados, princípios, intuição — qual?)

### Critérios de Registro

- [ ] Decisões estratégicas (escopo, budget > R$5k, parceria) são sempre registradas
- [ ] Decisões que afetam comunidade são sempre registradas
- [ ] Decisões de risco (nível 3+) são sempre registradas
- [ ] Decisões de "não fazer" são registradas com igual importância
- [ ] Existe critério claro para equipe saber quais decisões devem ser logadas

### Acessibilidade e Transparência

- [ ] Decision log é acessível a toda a equipe do movimento
- [ ] Decisões são pesquisáveis por data, tema, decisor e resultado
- [ ] Decision log é referenciado quando discussões antigas ressurgem (evitar re-litigar)
- [ ] Novos membros da equipe usam o log para entender histórico de decisões
- [ ] Stakeholders têm acesso a decisões que os afetam

### Revisão e Aprendizado

- [ ] Decisões passadas são revisadas trimestralmente (acertamos ou erramos?)
- [ ] Decisões que se revelaram erradas são marcadas com aprendizado
- [ ] Padrões de erro são identificados para melhorar qualidade de decisão futura
- [ ] Decisões bem-sucedidas são estudadas para replicar processo
- [ ] O processo de decisão em si é avaliado (não apenas o resultado)

## Critérios de Aprovação

- Todos os itens de "Estrutura do Registro" devem estar completos
- Todos os itens de "Critérios de Registro" devem estar completos
- Pelo menos 4 de 5 itens de "Acessibilidade" devem estar completos
- Todos os itens de "Revisão e Aprendizado" devem estar completos

## Ação se Falhar

1. Criar decision log template e repositório em até 1 semana
2. Retroativamente documentar as 10 decisões mais importantes dos últimos 3 meses
3. Incluir registro de decisão como etapa em todo meeting de decisão estratégica
4. Designar 1 pessoa como guardião do decision log (garante preenchimento)
5. Agendar revisão trimestral de decisões como ritual obrigatório da equipe
