# Validação de Códigos Culturais

## Objetivo

Verificar que os códigos culturais usados pelo movimento (referências, símbolos,
estéticas, comportamentos) são genuínos e atuais para o público-alvo. Código
cultural errado é como piada que precisa ser explicada — perde toda a força.

## Checklist

### Mapeamento de Códigos

- [ ] Pelo menos 10 códigos culturais do público-alvo estão catalogados (músicas, memes, estéticas, marcas, comportamentos)
- [ ] Cada código tem fonte de evidência (não é suposição da equipe)
- [ ] Códigos são classificados por penetração: mainstream, nicho, underground
- [ ] Códigos em declínio estão sinalizados para evitar uso tardio
- [ ] Códigos emergentes estão identificados para uso oportuno

### Validação com Público

- [ ] Pelo menos 5 códigos foram validados diretamente com membros do público-alvo
- [ ] Nenhum código é usado baseado apenas em pesquisa desk (precisa de validação humana)
- [ ] Reação emocional ao código foi observada (não só confirmação racional)
- [ ] Contexto de uso correto foi validado (código usado no momento e lugar certos)
- [ ] Códigos que geram reação negativa foram documentados e excluídos

### Aplicação nos Conteúdos

- [ ] Códigos culturais são usados como referência sutil, não como tema central (evita "hello fellow kids")
- [ ] Cada peça de conteúdo usa no máximo 2 códigos culturais simultâneos
- [ ] Códigos são adaptados ao formato do canal (meme no Instagram, referência verbal no podcast)
- [ ] A equipe de conteúdo entende o significado profundo de cada código que usa
- [ ] Existe lista de códigos culturais proibidos (concorrentes, ofensivos, desgastados)

### Monitoramento de Relevância

- [ ] Validade dos códigos é revisada mensalmente (cultura muda rápido)
- [ ] Novos códigos são incorporados dentro de 2 semanas da identificação
- [ ] Performance de conteúdos com códigos culturais é comparada com conteúdos sem
- [ ] Feedback da comunidade sobre uso de referências é coletado e analisado

## Critérios de Aprovação

- Todos os itens de "Mapeamento de Códigos" devem estar completos
- Pelo menos 4 de 5 itens de "Validação com Público" devem estar completos
- Todos os itens de "Aplicação nos Conteúdos" devem estar completos
- Todos os itens de "Monitoramento de Relevância" devem estar completos

## Ação se Falhar

1. Imergir em ambientes do público por 1 semana (fóruns, redes, eventos)
2. Criar painel de referências culturais com exemplos visuais e verbais
3. Recrutar 3 "insiders culturais" como consultores informais
4. Auditar últimos 10 conteúdos por uso correto/incorreto de códigos
5. Implementar "culture check" como etapa obrigatória na produção de conteúdo
