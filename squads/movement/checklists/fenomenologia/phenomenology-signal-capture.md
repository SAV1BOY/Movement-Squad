# Qualidade da Captura de Sinais

## Objetivo

Avaliar se o processo de captura de sinais culturais e comportamentais do público-alvo
está gerando insights acionáveis e não apenas ruído. Sinal sem qualidade é pior que
nenhum sinal — gera falsa confiança em decisões erradas.

## Checklist

### Fontes de Captura

- [ ] Pelo menos 5 fontes distintas de sinais estão ativas (redes sociais, fóruns, entrevistas, buscas, reviews)
- [ ] Cada fonte tem frequência de coleta definida (diária, semanal, contínua)
- [ ] Fontes incluem tanto ambientes públicos quanto conversas privadas (com consentimento)
- [ ] Fontes cobrem diferentes estágios de consciência do público (não sabe → sabe → busca solução)
- [ ] Existe pelo menos 1 fonte offline (evento, conversa presencial, ligação)

### Qualidade dos Sinais

- [ ] Sinais são registrados com contexto completo (fonte, data, volume, sentimento)
- [ ] Cada sinal tem classificação de força (fraco/moderado/forte) baseada em frequência e intensidade
- [ ] Sinais são diferenciados entre opinião individual vs padrão emergente
- [ ] Viés do coletor é reconhecido e mitigado (não buscar só confirmação)
- [ ] Existe critério para descartar sinais irrelevantes (filtro de ruído documentado)

### Processamento e Síntese

- [ ] Sinais brutos são transformados em insights acionáveis em até 72 horas
- [ ] Existe template padronizado para documentar insights (sinal → interpretação → ação sugerida)
- [ ] Insights são categorizados por tema e urgência
- [ ] Contradições entre sinais são explicitamente documentadas (não ignoradas)
- [ ] Síntese semanal é compartilhada com equipe do movimento

### Validação e Uso

- [ ] Insights influenciam decisões concretas de conteúdo e estratégia (rastreável)
- [ ] Pelo menos 3 decisões do último mês foram baseadas em sinais capturados
- [ ] Insights são validados com amostra do público antes de virar ação grande
- [ ] Existe feedback loop: ação baseada em insight → medição de resultado
- [ ] Arquivo de sinais históricos é consultável para identificar tendências

## Critérios de Aprovação

- Todos os itens de "Fontes de Captura" devem estar completos
- Pelo menos 4 de 5 itens de "Qualidade dos Sinais" devem estar completos
- Todos os itens de "Processamento e Síntese" devem estar completos
- Pelo menos 3 de 4 itens de "Validação e Uso" devem estar completos

## Ação se Falhar

1. Expandir fontes de captura adicionando pelo menos 2 novas fontes em 1 semana
2. Criar template de registro de sinais e treinar equipe no uso
3. Implementar ritual semanal de síntese de sinais (30 min, toda segunda-feira)
4. Conectar insights a backlog de ações com owner e prazo definidos
5. Revisar qualidade de captura mensalmente com métricas de utilização dos insights
