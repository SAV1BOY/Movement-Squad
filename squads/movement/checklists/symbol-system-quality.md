# Qualidade do Sistema de Símbolos Visuais

## Objetivo

Validar que o sistema de símbolos visuais do movimento é consistente, reconhecível à
distância e reproduzível pela comunidade sem ferramentas profissionais. Símbolos são a
linguagem silenciosa do movimento — precisam funcionar em um avatar de 32px, em um
lambe-lambe na rua e em um palco de evento.

## Quando Usar

- Antes de publicar o sistema visual pela primeira vez
- Quando novos elementos visuais forem adicionados ao sistema
- Na expansão para formatos físicos (merch, eventos, print)
- Quando a comunidade usar os símbolos de forma inconsistente ou distorcida
- Em auditorias semestrais da saúde visual do movimento

## Agentes Responsáveis

- **Creative Director Agent** — Autor e guardião do sistema visual
- **Identity & Culture Agent** — Valida que os símbolos expressam a identidade
- **Content & Memetics Agent** — Testa aplicação em conteúdo do dia a dia
- **Review & QA Agent** — Executa este checklist como quality gate

## Checklist

### 1. Consistência

- [ ] 1.1 A paleta de cores primária está definida com códigos hex/RGB exatos
- [ ] 1.2 A paleta de cores secundária e regras de uso estão documentadas
- [ ] 1.3 A tipografia principal e secundária estão definidas com hierarquia de uso
- [ ] 1.4 As fontes escolhidas são gratuitas ou licenciadas para uso pela comunidade
- [ ] 1.5 O brandbook ou guia visual está acessível a todos que produzem conteúdo
- [ ] 1.6 Existe kit de assets visuais pronto para download (logos, templates, ícones)

### 2. Reconhecibilidade

- [ ] 2.1 O símbolo principal é reconhecível em tamanho mínimo de 32x32 pixels
- [ ] 2.2 O símbolo funciona em fundo claro e fundo escuro (testado)
- [ ] 2.3 O símbolo se diferencia de outros movimentos e marcas no mesmo espaço cultural
- [ ] 2.4 Uma pessoa exposta ao símbolo 3 vezes o reconhece na quarta exposição (teste)
- [ ] 2.5 O símbolo carrega significado conectado à tese do movimento (não é decorativo)

### 3. Reprodutibilidade

- [ ] 3.1 O símbolo pode ser desenhado à mão por uma pessoa sem treinamento artístico
- [ ] 3.2 O símbolo funciona em preto e branco puro (sem depender de cor)
- [ ] 3.3 Os templates visuais podem ser editados com Canva ou ferramentas gratuitas
- [ ] 3.4 Existe tutorial ou guia passo a passo para a comunidade criar conteúdo no padrão visual
- [ ] 3.5 As variações permitidas do símbolo estão documentadas (o que pode e não pode mudar)

### 4. Aplicação Cross-Formato

- [ ] 4.1 O sistema visual funciona em formato digital (stories, feed, banner, email)
- [ ] 4.2 O sistema visual funciona em formato físico (camiseta, adesivo, poster)
- [ ] 4.3 O sistema visual funciona em vídeo (lower third, intro, watermark)
- [ ] 4.4 O sistema visual funciona em formatos de comunidade (badges, emojis, banners)
- [ ] 4.5 Mockups de aplicação em pelo menos 5 formatos diferentes foram produzidos

### 5. Governança Visual

- [ ] 5.1 O processo de aprovação de novos elementos visuais está definido
- [ ] 5.2 Usos incorretos ou distorcidos do símbolo têm protocolo de correção
- [ ] 5.3 A comunidade tem canal para submeter criações visuais para feedback
- [ ] 5.4 Existe revisão periódica do sistema visual com base em feedback da comunidade

## Critérios de Aprovação

- **Aprovado:** Todos os 25 itens completos com brandbook e kit de assets entregues
- **Aprovado com ressalvas:** Até 3 itens pendentes, nenhum do grupo "Reconhecibilidade"
- **Reprovado:** 4+ itens pendentes, ou símbolo não reconhecível em teste real

## Ação se Falhar

1. Devolver ao Creative Director Agent para redesenho dos elementos frágeis
2. Se reconhecibilidade falhar, simplificar o símbolo (menos é mais)
3. Se reprodutibilidade falhar, criar versão simplificada para uso comunitário
4. Se consistência falhar, produzir brandbook mínimo antes de qualquer publicação
5. Testar com 10 pessoas da audiência antes de re-submeter
