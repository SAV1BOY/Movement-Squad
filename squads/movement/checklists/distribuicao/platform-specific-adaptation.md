# Adaptação Específica por Plataforma

## Objetivo

Verificar que cada plataforma de distribuição recebe conteúdo adaptado às suas
especificidades técnicas, culturais e algorítmicas. Postar a mesma coisa em todas
as plataformas é a estratégia mais preguiçosa e menos eficaz possível.

## Checklist

### Adaptação Técnica

- [ ] Dimensões de imagem/vídeo estão corretas para cada plataforma (sem barras pretas ou cortes)
- [ ] Duração de vídeo respeita sweet spot da plataforma (Reels 15-30s, YouTube 8-15min, TikTok 15-60s)
- [ ] Legendas/captions estão otimizados para limites de caracteres de cada plataforma
- [ ] Hashtags são customizadas por plataforma (quantidade e relevância variam)
- [ ] Thumbnail/capa é otimizada por plataforma (preview em feed vs busca vs discovery)

### Adaptação Cultural

- [ ] Tom de voz é ajustado ao público de cada plataforma (LinkedIn profissional, TikTok informal)
- [ ] Trends e formatos nativos são aproveitados quando relevantes (áudios virais, templates trending)
- [ ] Linguagem das primeiras linhas/segundos é otimizada para padrão de consumo da plataforma
- [ ] CTA é adequado ao comportamento da plataforma (salvar no Instagram, comentar no LinkedIn)
- [ ] Horário de publicação é otimizado por plataforma com base em dados reais

### Adaptação Algorítmica

- [ ] Boas práticas de algoritmo estão documentadas e atualizadas por plataforma
- [ ] Conteúdo segue recomendações de distribuição de cada plataforma (ex: Instagram prioriza Reels)
- [ ] Práticas penalizadas são evitadas (watermark de outra plataforma, links em caption do Instagram)
- [ ] Engagement baiting é evitado em favor de engajamento genuíno
- [ ] Mudanças de algoritmo são monitoradas e adaptações são feitas em até 1 semana

### Mensuração por Plataforma

- [ ] Métricas de sucesso são específicas por plataforma (não comparar views de TikTok com LinkedIn)
- [ ] Benchmark de performance é de mercado similar na mesma plataforma (não cross-platform)
- [ ] Performance por tipo de conteúdo é rastreada separadamente em cada plataforma
- [ ] Plataforma de pior performance relativa é avaliada trimestralmente (manter, ajustar ou sair)

## Critérios de Aprovação

- Todos os itens de "Adaptação Técnica" devem estar completos
- Todos os itens de "Adaptação Cultural" devem estar completos
- Pelo menos 4 de 5 itens de "Adaptação Algorítmica" devem estar completos
- Todos os itens de "Mensuração por Plataforma" devem estar completos

## Ação se Falhar

1. Criar guia de especificações por plataforma em documento acessível (1 página por plataforma)
2. Eliminar cross-posting sem adaptação imediatamente
3. Designar especialista por plataforma principal (mesmo que mesma pessoa cuide de 2)
4. Implementar QA técnico antes de publicação (checklist de dimensão, duração, hashtags)
5. Analisar top 10 conteúdos de cada plataforma para extrair padrões de sucesso
