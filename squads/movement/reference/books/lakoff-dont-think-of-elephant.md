# Don't Think of an Elephant! — George Lakoff (2004)

## Resumo

George Lakoff, linguista cognitivo de Berkeley, argumenta que a forma como enquadramos uma questão determina como as pessoas a pensam. O título do livro é sua demonstração mais elegante: ao dizer "não pense em um elefante", você automaticamente pensa em um elefante. Negar um frame o reforça.

A tese central é que frames — estruturas mentais que moldam a forma como vemos o mundo — são mais poderosos que fatos. Quando os fatos contradizem o frame, o frame permanece e os fatos são descartados. Isso significa que a batalha política (e cultural) fundamental não é sobre informação — é sobre frames.

Lakoff demonstra que frames são ativados por linguagem específica. As palavras que escolhemos não são neutras — cada palavra ativa uma rede de associações que enquadra o problema e suas soluções possíveis. Quem define os termos do debate ganha o debate antes que ele comece.

O livro também introduz a ideia de que todo pensamento político é metafórico: conservadores operam com a metáfora do "pai estrito" e progressistas com a do "pai nutritivo". Essas metáforas profundas determinam posições em dezenas de questões aparentemente desconectadas.

Para movimentos culturais, a lição é que a escolha de linguagem e enquadramento é a decisão estratégica mais fundamental — mais importante que orçamento, canais ou táticas.

## Conceitos-Chave

### 1. Frame (Enquadramento)
Estrutura mental que organiza a forma como entendemos uma situação. Frames determinam quais fatos parecem relevantes e quais soluções parecem razoáveis.

### 2. Não Negue o Frame
Negar o frame do oponente o reforça. A estratégia correta é criar um frame alternativo, nunca argumentar dentro do frame do outro.

### 3. Metáforas Profundas
Estruturas metafóricas fundamentais que organizam o pensamento sobre questões complexas. São inconscientes e moldadas pela cultura e experiência.

### 4. Linguagem como Ativadora de Frames
Cada palavra ativa redes de associação. Escolher palavras é escolher frames. "Alívio fiscal" vs. "investimento público" enquadram o mesmo tema de formas opostas.

### 5. Fatos vs. Frames
Quando fatos contradizem frames, os frames geralmente vencem. Informação não muda mentes — reframing muda mentes.

### 6. Pensamento Biconceptual
Muitas pessoas operam com frames diferentes para questões diferentes. Não são puramente "de um lado" — são biconceptuais, com frames variados por assunto.

## Insights Aplicáveis ao Movement Squad

- O framing é a decisão estratégica número um — deve ser definido antes de qualquer outra decisão de comunicação.
- Nunca argumentar dentro do frame da oposição ou do status quo — criar um frame alternativo próprio.
- As palavras-chave do movimento devem ser escolhidas como armas de framing, não como descrições neutras.
- Fatos sozinhos não convencem — devem ser apresentados dentro de um frame que lhes dê significado.
- O vocabulário do movimento é estratégia — cada termo deve ser testado por qual frame ativa.
- Compreender os frames existentes da audiência antes de tentar introduzir novos.
- O reframing é um processo gradual — repetição consistente do novo frame é necessária para substituir o antigo.

## Frameworks Extraídos

### Framework de Design de Frame para Movimentos
1. Identificar o frame dominante que enquadra a categoria/questão
2. Analisar que visão de mundo esse frame reforça
3. Criar um frame alternativo que reorganize a questão favoravelmente
4. Selecionar linguagem que ative o novo frame sem reforçar o antigo
5. Testar o frame com audiência para verificar que associações ativa
6. Repetir consistentemente até que o novo frame se estabeleça

### Framework de Auditoria de Linguagem
1. Listar todas as palavras-chave usadas pelo movimento
2. Para cada palavra, identificar que frame ela ativa
3. Verificar se alguma palavra reforça inadvertidamente o frame do status quo
4. Substituir palavras problemáticas por alternativas que ativem o frame desejado
5. Garantir consistência de vocabulário em todos os pontos de contato

## Citações Memoráveis

- "Não pense em um elefante. Você pensou, não é? Negar um frame o reforça. A única saída é criar um frame diferente."
- "Fatos não convencem. Frames convencem. Os fatos só são percebidos quando encaixam no frame que a pessoa já tem."
- "Quem define os termos do debate ganha o debate antes que ele comece."
- "Toda palavra é uma escolha política. Não existe linguagem neutra quando se trata de questões que importam."
