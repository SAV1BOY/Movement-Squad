# Cynefin Framework — Dave Snowden (Resources + HBR)

## Resumo

Dave Snowden desenvolveu o framework Cynefin (pronuncia-se "ku-NE-vin", palavra galesa para "habitat") como uma ferramenta de sense-making — ajudar líderes a entenderem em que tipo de sistema estão operando antes de decidir como agir. O artigo seminal na Harvard Business Review, "A Leader's Framework for Decision Making", popularizou o framework para audiências de gestão.

A premissa fundamental é que diferentes contextos exigem diferentes abordagens de liderança e decisão. O erro mais comum é aplicar ferramentas de contextos simples ou complicados em contextos complexos — como tentar planilhar a emergência de um movimento cultural ou prever o comportamento de redes sociais com modelos lineares.

Cynefin define cinco domínios: Claro (regras conhecidas, melhores práticas), Complicado (análise de especialistas, boas práticas), Complexo (experimentação e emergência, práticas emergentes), Caótico (ação rápida, práticas inéditas) e Desordem (quando não se sabe em qual domínio se está). A maioria dos desafios de movimentos culturais opera no domínio complexo.

Para o Movement Squad, Cynefin é crucial porque evita dois erros fatais: tratar movimentos como projetos previsíveis (excesso de planejamento) ou como caos total (ausência de estratégia). Movimentos operam na complexidade — exigem experimentação, sondagem e resposta adaptativa.

## Conceitos-Chave

### 1. Domínio Claro (Óbvio)
Relações de causa e efeito são óbvias. Abordagem: Perceber → Categorizar → Responder. Melhores práticas existem e devem ser seguidas.

### 2. Domínio Complicado
Causa e efeito existem mas exigem análise especializada. Abordagem: Perceber → Analisar → Responder. Múltiplas boas práticas possíveis.

### 3. Domínio Complexo
Causa e efeito só são perceptíveis em retrospectiva. Abordagem: Sondar → Perceber → Responder. Práticas emergentes descobertas por experimentação.

### 4. Domínio Caótico
Não há relações de causa e efeito perceptíveis. Abordagem: Agir → Perceber → Responder. Estabilizar primeiro, depois migrar para complexo.

### 5. Desordem
Quando não se sabe em qual domínio se está. O estado mais perigoso porque as pessoas aplicam o framework que lhes é mais confortável, não o mais adequado.

### 6. Liminaridade (Boundaries)
As transições entre domínios são tão importantes quanto os domínios em si. A queda do domínio claro para o caótico (complacência) é particularmente perigosa.

### 7. Sondas Seguras para Falhar
No domínio complexo, a estratégia correta é lançar múltiplas sondas (experimentos) que são seguras para falhar. Amplificar o que funciona, amortecer o que não funciona.

## Insights Aplicáveis ao Movement Squad

- Movimentos culturais operam predominantemente no domínio complexo — requerem experimentação, não planejamento detalhado.
- A tentação de tratar movimentos como projetos complicados (planejáveis por especialistas) é o erro mais comum e destrutivo.
- "Sondas seguras para falhar" devem ser a unidade básica de ação — múltiplos experimentos pequenos em vez de uma grande aposta.
- Amplificar o que emerge positivamente é mais eficaz que tentar prever e executar o que "deveria" funcionar.
- A desordem deve ser identificada rapidamente — quando não sabemos o contexto, o primeiro passo é diagnosticar, não agir.
- Diferentes aspectos do mesmo movimento podem estar em domínios diferentes — logística pode ser complicada enquanto cultura é complexa.
- O framework protege contra dois vícios: o excesso de planejamento (tratar tudo como complicado) e o excesso de improvisação (tratar tudo como caótico).

## Frameworks Extraídos

### Framework Cynefin Aplicado a Movimentos
1. **Diagnóstico de Domínio**: Em que domínio está cada aspecto do movimento?
2. **Aspectos Claros**: Identificar e automatizar (processos operacionais, logística)
3. **Aspectos Complicados**: Trazer especialistas (análise de dados, pesquisa)
4. **Aspectos Complexos**: Projetar sondas experimentais (testes de narrativa, formatos, canais)
5. **Aspectos Caóticos**: Agir rápido para estabilizar (crises, reações inesperadas)
6. **Revisão**: Reclassificar periodicamente conforme o contexto evolui

### Framework de Sondas para Movimentos
1. Projetar múltiplas sondas pequenas e diversas
2. Garantir que cada sonda é "segura para falhar" (baixo custo, baixo risco)
3. Lançar sondas simultaneamente em múltiplas direções
4. Monitorar resultados com curiosidade, não com expectativas fixas
5. Amplificar sondas que mostram tração positiva
6. Amortecer ou eliminar sondas que não funcionam
7. Documentar aprendizados para informar próxima rodada

## Citações Memoráveis

- "Em sistemas complexos, a relação entre causa e efeito só é visível em retrospectiva. Planejamento detalhado é uma ilusão reconfortante."
- "O erro mais perigoso em liderança é aplicar ferramentas de um contexto em outro. Planilhas não resolvem complexidade."
- "No complexo, a estratégia correta é sondar, perceber e responder — não planejar, executar e controlar."
- "Sondas seguras para falhar são o motor da descoberta. Se você não pode errar barato, não pode aprender rápido."

## Aplicação Prática

### Exercício de Diagnóstico de Domínio
Protocolo para classificar cada aspecto do movimento por domínio Cynefin:

1. **Listagem**: Listar todos os desafios e atividades atuais do movimento.
2. **Classificação**: Para cada item, responder: "podemos prever o resultado com base em experiência anterior?"
3. **Atribuição de Domínio**: Sim com certeza = Claro. Sim com análise = Complicado. Não, precisamos experimentar = Complexo. Caos = Caótico.
4. **Estratégia por Domínio**: Atribuir a abordagem correta para cada domínio.
5. **Design de Sondas**: Para itens complexos, projetar 3-5 sondas seguras para falhar.

### Armadilhas Comuns
- Tratar o domínio complexo como complicado (excesso de planejamento e análise)
- Tratar o domínio complicado como complexo (experimentação quando uma análise resolveria)
- Não reconhecer quando se está na Desordem — o estado mais perigoso
- Falhar em reclassificar domínios conforme o contexto evolui
