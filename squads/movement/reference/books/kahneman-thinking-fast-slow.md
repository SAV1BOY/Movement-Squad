# Thinking, Fast and Slow — Daniel Kahneman (2011)

## Resumo

Kahneman, vencedor do Nobel de Economia, sintetiza décadas de pesquisa sobre como a mente humana realmente funciona — em contraste com o modelo de racionalidade perfeita. A descoberta central é que possuímos dois "sistemas" de pensamento: o Sistema 1 (rápido, intuitivo, emocional, automático) e o Sistema 2 (lento, deliberativo, lógico, esforçado).

A maioria das decisões humanas é tomada pelo Sistema 1, não pelo Sistema 2. Isso significa que as pessoas decidem com base em heurísticas (atalhos mentais), vieses cognitivos e emoções — não em análise racional cuidadosa. O Sistema 2 é frequentemente recrutado apenas para racionalizar decisões que o Sistema 1 já tomou.

Kahneman documenta dezenas de vieses cognitivos que distorcem sistematicamente o julgamento humano: ancoragem, disponibilidade, representatividade, aversão à perda, efeito de enquadramento, entre muitos outros. Esses vieses não são bugs — são features de um sistema cognitivo que evoluiu para decisões rápidas, não para precisão.

Para o Movement Squad, este livro é a base cognitiva que fundamenta quase todas as outras estratégias de influência, comunicação e mobilização. Entender como a mente realmente decide é pré-requisito para projetar movimentos eficazes.

## Conceitos-Chave

### 1. Sistema 1 e Sistema 2
Sistema 1: automático, rápido, emocional, intuitivo. Sistema 2: controlado, lento, racional, esforçado. A maioria das decisões é do Sistema 1.

### 2. Heurística de Disponibilidade
A tendência de julgar a probabilidade de eventos com base em quão facilmente exemplos vêm à mente. Eventos vívidos e recentes são superestimados.

### 3. Ancoragem
O primeiro número ou informação que recebemos funciona como "âncora" que influencia todas as estimativas subsequentes, mesmo quando é completamente arbitrário.

### 4. Aversão à Perda
A dor de perder é aproximadamente duas vezes mais forte que o prazer de ganhar a mesma quantia. As pessoas fazem mais para evitar perdas do que para obter ganhos.

### 5. Efeito de Enquadramento (Framing Effect)
A mesma informação apresentada de formas diferentes produz decisões diferentes. "90% de chance de sobreviver" vs. "10% de chance de morrer" mudam a decisão.

### 6. WYSIATI (What You See Is All There Is)
O Sistema 1 constrói a melhor história possível com a informação disponível, sem considerar que informação pode estar faltando. Conclusões precipitadas são a norma.

### 7. Substituição
Quando enfrentamos uma pergunta difícil, inconscientemente a substituímos por uma pergunta mais fácil e respondemos essa. "Esse investimento é bom?" vira "eu gosto dessa empresa?".

## Insights Aplicáveis ao Movement Squad

- Toda comunicação de movimento é processada primeiro pelo Sistema 1 — projetar para intuição e emoção, não apenas para lógica.
- A ancoragem pode ser usada estrategicamente — o primeiro frame, número ou referência determina como todo o resto é avaliado.
- A aversão à perda é mais motivadora que a promessa de ganho — enquadrar a não-adesão como perda, não a adesão como ganho.
- O efeito de enquadramento significa que a mesma proposta pode ser aceita ou rejeitada dependendo da apresentação.
- WYSIATI implica que a narrativa do movimento deve ser completa e autossuficiente — a audiência não buscará informação faltante.
- Vieses cognitivos não são defeitos a serem corrigidos — são a realidade operacional do público. Projetar para como as pessoas realmente pensam.
- O Sistema 2 é preguiçoso — se a mensagem exigir esforço cognitivo, será ignorada.

## Frameworks Extraídos

### Framework de Design Cognitivo para Movimentos
1. **Para o Sistema 1**: Mensagem simples, emocional, visual, com âncora favorável
2. **Contra vieses**: Usar enquadramento que alinhe vieses com o objetivo do movimento
3. **Aversão à perda**: Enquadrar custo de não-aderir, não apenas benefício de aderir
4. **Ancoragem**: Definir a primeira referência que a audiência recebe
5. **Disponibilidade**: Criar experiências vívidas e memoráveis que venham facilmente à mente
6. **WYSIATI**: Garantir que a narrativa é completa e não depende de busca adicional

### Framework de Auditoria de Vieses
1. Quais vieses cognitivos estão operando no contexto da decisão de adesão?
2. Algum viés está trabalhando contra o movimento?
3. Como enquadrar a mensagem para alinhar vieses com o objetivo?
4. A mensagem funciona no nível do Sistema 1 (rápido e intuitivo)?
5. O Sistema 2 é ativado apenas para reforçar, não para questionar?

## Citações Memoráveis

- "Quando a mente se depara com uma pergunta difícil, silenciosamente a substitui por uma pergunta mais fácil — e responde essa."
- "O Sistema 1 é uma máquina de criar histórias coerentes. Não importa se a história é verdadeira — importa que seja boa."
- "A dor de perder é o dobro do prazer de ganhar. As pessoas não são maximizadoras de ganho — são minimizadoras de perda."
- "Confiamos demais no que vemos e subestimamos o que não vemos. WYSIATI é o viés mais perigoso de todos."
