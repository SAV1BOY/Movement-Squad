# Fluxo de Escala: Local → Regional → Global

## Objetivo

Gerenciar a expansão controlada do movimento — de nicho para mainstream, de local para global — preservando autenticidade e profundidade comunitária enquanto amplia alcance e impacto.

## Diagrama de Fases

```
[FASE 1]          [FASE 2]          [FASE 3]          [FASE 4]          [FASE 5]
Diagnóstico   →   Preparação    →   Piloto de     →   Scaling         → Consolidação
de Prontidão      para Escala       Expansão          Controlado         e Review
   |                 |                  |                  |                  |
   v                 v                  v                  v                  v
Score de         Infraestrutura,   Teste em 1-2      Rollout para       Métricas,
prontidão,       playbooks,        novos             múltiplos          aprendizados,
gatilhos ok      líderes locais    segmentos/regiões segmentos          próxima fase
```

## Fases Detalhadas

### Fase 1: Diagnóstico de Prontidão (Semana 1)

**Agentes:** analista-de-impacto, movement-architect

**Inputs:**
- Community Health Score e métricas de profundidade
- Win Conditions e progresso
- Scaling Plan aprovado
- Gatilhos de escala definidos

**Ações:**
1. Verificar gatilhos de escala: NPS comunidade > 70? Taxa de contribuição > 15%? Champions ativos suficientes? Thesis estável?
2. Avaliar saúde do core: a comunidade existente está forte o bastante para sobreviver à expansão?
3. Identificar riscos de diluição específicos para o momento atual
4. Calcular Scaling Readiness Score (0-100)
5. Recomendar: escalar, esperar ou fortalecer core

**Outputs:**
- Scaling Readiness Score
- Riscos identificados
- Recomendação fundamentada

**Decision Gate:**
- Score >= 75 + gatilhos atingidos → avançar para preparação
- Score 50-75 → fortalecer itens específicos antes de escalar
- Score < 50 → não escalar, focar em core

### Fase 2: Preparação para Escala (Semanas 2-3)

**Agentes:** estrategista-de-ciclo, movement-architect

**Inputs:**
- Recomendação de escala aprovada
- Segmentos/regiões target para expansão
- Recursos disponíveis

**Ações:**
1. Definir primeiro segmento/região para piloto de expansão
2. Adaptar thesis e messaging para novo público (o que é universal, o que adapta)
3. Recrutar e treinar líderes/champions locais para o novo segmento
4. Preparar artefatos adaptados (linguagem, referências, estética)
5. Configurar infraestrutura: novo canal, sub-comunidade, tracking separado
6. Criar playbook de expansão com do's e don'ts

**Outputs:**
- Segmento piloto definido
- Líderes locais recrutados
- Artefatos adaptados
- Playbook de expansão

**Decision Gate:**
- Preparação completa → lançar piloto
- Líderes insuficientes → recrutar mais antes de lançar

### Fase 3: Piloto de Expansão (Semanas 4-7)

**Agentes:** movement-chief, movement-architect

**Inputs:**
- Playbook de expansão
- Artefatos adaptados
- Líderes locais treinados

**Ações:**
1. Lançar presença no novo segmento/região com inner circle local
2. Ativar onboarding adaptado para novos membros
3. Rodar rituais com adaptação local
4. Monitorar métricas separadamente do core: retenção, engajamento, sentimento
5. Coletar feedback intensivo dos novos membros
6. Verificar se expansão impacta negativamente o core (cannibalização)
7. Iterar com base em dados do piloto

**Outputs:**
- Piloto em operação
- Métricas de piloto capturadas
- Feedback coletado
- Impacto no core monitorado

**Decision Gate:**
- Piloto saudável + core estável → expandir para mais segmentos
- Piloto saudável + core impactado → ajustar antes de expandir mais
- Piloto fraco → diagnosticar e iterar ou cancelar expansão

### Fase 4: Scaling Controlado (Semanas 8-11)

**Agentes:** todos

**Inputs:**
- Resultados do piloto validados
- Playbook refinado com learnings
- Recursos para expansão adicional

**Ações:**
1. Aplicar playbook refinado para 2-3 segmentos/regiões adicionais
2. Ativar efeitos de rede: referral program, content compartilhável, status social
3. Descentralizar liderança: empoderar champions locais
4. Manter coesão narrativa: cross-community sync semanal
5. Monitorar métricas por segmento e no agregado
6. Escalar infraestrutura conforme crescimento

**Outputs:**
- Expansão em múltiplos segmentos
- Liderança descentralizada operante
- Efeitos de rede ativados
- Métricas por segmento

**Decision Gate:**
- Crescimento saudável em múltiplos segmentos → continuar
- Crescimento em alguns, falha em outros → focar nos que funcionam
- Diluição detectada → pausar e reconsolidar

### Fase 5: Consolidação e Review (Semana 12)

**Agentes:** movement-architect, analista-de-impacto

**Inputs:**
- Dados completos de todo o período de expansão
- Feedback de todas as comunidades
- Métricas de impacto em negócio

**Ações:**
1. Consolidar métricas de todos os segmentos expandidos
2. Comparar saúde do core pré e pós-expansão
3. Documentar learnings e atualizar playbook
4. Calcular ROI da expansão
5. Definir próxima fase de escala (se aplicável)

**Outputs:**
- Scaling Report completo
- Playbook atualizado
- ROI calculado
- Plano para próxima fase

**Decision Gate:**
- Expansão bem-sucedida → planejar próxima onda
- Expansão parcial → consolidar antes de expandir mais
- Expansão fracassou → retornar ao core e reavaliar estratégia

## Cadência

- **Ciclo completo:** 12 semanas (trimestral)
- **Diagnóstico:** Início do trimestre
- **Preparação:** 2 semanas
- **Piloto:** 4 semanas
- **Scaling:** 4 semanas
- **Consolidação:** 1 semana

## Artefatos Produzidos

- Scaling Readiness Score
- Playbook de expansão (atualizado)
- Artefatos adaptados por segmento/região
- Scaling Report
- Métricas por segmento

## Métricas de Sucesso

| Métrica | Meta |
|---------|------|
| Scaling Readiness Score | >= 75 antes de expandir |
| Retenção D30 em novo segmento | >= 40% |
| Impacto no core (retenção) | < -5% de variação |
| Champions locais ativos | >= 3 por segmento |
| Engajamento novo segmento | >= 70% do core |
| ROI da expansão | Positivo em 90 dias |

### Regras de Fluxo
- **Quality Gate entre fases:** Diagnóstico→Preparação: Scaling Readiness Score ≥ 75; Piloto→Scaling: retenção D30 ≥ 40% em novo segmento; Scaling→Consolidação: impacto no core < -5%
- **Rework:** Se diluição detectada durante scaling → pausar expansão e reconsolidar core
- **Escalation:** Se expansão fracassa → escalar para Movement Chief para decisão de retorno ao core
- **Handoff:** Scaling Report alimenta → `workflows/16-quarterly-movement-review.md`
