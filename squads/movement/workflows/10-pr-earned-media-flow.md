# Fluxo de PR: Ângulo → Pitch → Placement → Amplify → Measure

## Objetivo

Operar o pipeline de PR e earned media do movimento — da criação de ângulos jornalísticos à medição de impacto da cobertura — conquistando presença em veículos relevantes que legitimam o movimento como fenômeno cultural.

## Diagrama de Fases

```
[ÂNGULO]         [PITCH]          [PLACEMENT]      [AMPLIFY]        [MEASURE]
Criar        →   Enviar e     →   Facilitar    →   Amplificar   →   Medir
Ângulos          Negociar         Entrevista       Cobertura        Impacto
   |                |                |                |                |
   v                v                v                v                v
8-12 ângulos     Pitches          Matéria          Repost,          Reach,
desenvolvidos    customizados     publicada        share,           sentiment,
                 enviados                          paid boost       brand lift
```

## Fases Detalhadas

### Fase 1: Criação de Ângulos (Dia 1-5)

**Agentes:** estrategista-movimento

**Inputs:**
- Thesis e tensões culturais
- Dados exclusivos ou insights novos
- Calendar de datas relevantes
- Histórias de membros da comunidade
- Milestones do movimento

**Ações:**
1. Brainstorm de 8-12 ângulos potenciais
2. Testar newsworthiness de cada um (6 critérios)
3. Desenvolver narrativa para top 5 ângulos: headline, lead, dados, personagem, contexto
4. Identificar porta-vozes por ângulo e preparar key messages
5. Produzir press kit atualizado

**Outputs:**
- 5+ ângulos desenvolvidos
- Porta-vozes designados e preparados
- Press kit atualizado

**Decision Gate:**
- >= 3 ângulos fortes → avançar para pitch
- Ângulos fracos → buscar novos dados ou histórias

### Fase 2: Pitch e Negociação (Dia 6-12)

**Agentes:** ativador-chefe

**Inputs:**
- Ângulos desenvolvidos
- Mapa de veículos e jornalistas
- Templates de pitch

**Ações:**
1. Personalizar pitches por jornalista/veículo
2. Executar outreach em ondas: tier 1 primeiro, tier 2 depois, tier 3 por último
3. Negociar exclusivas com tier 1 quando aplicável
4. Follow-up respeitoso (máximo 2 tentativas)
5. Gerenciar respostas e agendar entrevistas

**Outputs:**
- Pitches enviados
- Entrevistas agendadas
- Exclusivas negociadas

**Decision Gate:**
- Veículo tier 1 aceita → priorizar exclusiva
- Nenhum aceite → revisitar ângulos e timing
- Múltiplos aceites → coordenar para máximo impacto

### Fase 3: Placement (Dia 13-20)

**Agentes:** ativador-chefe, estrategista-movimento

**Inputs:**
- Entrevistas agendadas
- Porta-vozes preparados
- Material de apoio (dados, imagens, quotes)

**Ações:**
1. Preparar porta-vozes com briefing específico por veículo
2. Facilitar entrevistas (acompanhar se possível)
3. Enviar material complementar solicitado
4. Monitorar processo editorial (sem pressionar)
5. Preparar amplificação antes da publicação

**Outputs:**
- Entrevistas realizadas
- Material entregue
- Matérias em processo editorial

**Decision Gate:**
- Matéria confirmada → preparar amplificação
- Matéria cancelada → entender razão e ajustar para próxima

### Fase 4: Amplificação (Pós-publicação)

**Agentes:** ativador-chefe, community-builder

**Inputs:**
- Matéria publicada
- Canais do movimento
- Budget de amplificação (se aplicável)

**Ações:**
1. Compartilhar matéria em todos os canais do movimento
2. Enviar para comunidade com contexto
3. Agradecer jornalista publicamente e em privado
4. Considerar paid boost da matéria (credibilidade de terceiro)
5. Usar como prova social em pitches futuros
6. Champions compartilham em suas redes

**Outputs:**
- Cobertura amplificada
- Prova social acumulada
- Relação com jornalista fortalecida

**Decision Gate:**
- Cobertura positiva → maximizar amplificação
- Cobertura negativa → acionar protocolo de crise se necessário

### Fase 5: Medição de Impacto (Dia 25-30)

**Agentes:** analista-impacto

**Inputs:**
- Dados de cobertura (clippings, reach, sentiment)
- Dados de tráfego e conversão pós-cobertura
- Social listening pós-publicação

**Ações:**
1. Compilar clippings e cobertura total
2. Estimar reach e AVE (se stakeholders exigem)
3. Analisar sentimento da cobertura
4. Medir impacto em métricas: tráfego, search volume, community entries
5. Produzir PR Report mensal

**Outputs:**
- PR Report com métricas
- Clippings organizados
- Impact analysis

**Decision Gate:**
- PR gerando impacto → manter investimento e expandir relações
- PR sem impacto → revisitar estratégia de ângulos e veículos

## Cadência

- **Ciclo completo:** 30 dias (mensal)
- **Ângulos:** Primeira semana
- **Pitches:** Segunda semana
- **Placement:** Terceira semana
- **Amplify + Measure:** Quarta semana

## Artefatos Produzidos

- Ângulos de PR desenvolvidos
- Press Kit atualizado
- Pitches customizados
- Clippings de cobertura
- PR Report mensal

## Métricas de Sucesso

| Métrica | Meta |
|---------|------|
| Ângulos desenvolvidos/mês | >= 5 |
| Pitches enviados/mês | >= 15 |
| Taxa de resposta | >= 30% |
| Matérias publicadas/mês | >= 2 |
| Sentimento positivo/neutro | >= 85% |
| Tráfego incremental pós-PR | Rastreado |

### Regras de Fluxo
- **Quality Gate entre fases:** Ângulos→Pitches: ângulos aprovados; Pitches→Placement: veículos mapeados; Placement→Amplify: cobertura obtida; Amplify→Measure: dados coletados
- **Rework:** Se taxa de resposta < 30% → revisitar ângulos e veículos target
- **Escalation:** Se cobertura negativa inesperada → acionar `workflows/06-crisis-and-backlash.md`
- **Handoff:** PR Report alimenta → `workflows/04-measure-and-learn.md` e `workflows/05-ralphloop-kaizen-weekly.md`
