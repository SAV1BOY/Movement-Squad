# Thesis Forge: De Sinais à Tese e Identidade

## Objetivo

Transformar sinais culturais capturados em uma thesis de movimento coesa (Inimigo/Sonho/Mecanismo) e em um sistema de identidade coletiva — o processo fundacional que dá alma e forma ao movimento.

## Diagrama de Fases

```
[FASE 1]           [FASE 2]          [FASE 3]          [FASE 4]          [FASE 5]
Síntese de     →   Forja da      →   Validação     →   Identidade    →   Aprovação
Sinais              Thesis            e Stress          Coletiva          e Lançamento
                                      Test                                Interno
   |                  |                  |                  |                  |
   v                  v                  v                  v                  v
Clusters         Inimigo/Sonho/    Contra-narrativas   Códigos          Thesis Doc +
priorizados      Mecanismo         Inner circle        visuais/verbais/ Identity Kit
+ tensões        articulados       Linguagem real      comportamentais  aprovados
```

## Fases Detalhadas

### Fase 1: Síntese de Sinais (Semana 1)

**Agentes:** fenomenologo

**Inputs:**
- Todos os Signal Reports do trimestre
- Tension Map atualizado
- Mapa de linguagem do público
- Competitor Audit
- Trend Radar
- Entrevistas com membros

**Ações:**
1. Consolidar todos os clusters de sinais do trimestre em mapa unificado
2. Identificar os 3-5 clusters com maior intensidade e recorrência
3. Para cada cluster, formular a tensão cultural subjacente
4. Mapear espaços narrativos vazios (onde ninguém se posicionou)
5. Produzir documento de síntese: "Estado Cultural Atual" com recomendações

**Outputs:**
- Documento "Estado Cultural Atual"
- Top 3-5 tensões priorizadas
- Espaços narrativos vazios mapeados

**Decision Gate:**
- Tensões claras e documentadas → avançar para Fase 2
- Tensões fracas ou confusas → voltar para pesquisa de campo adicional

### Fase 2: Forja da Thesis (Semana 2)

**Agentes:** movement-architect, estrategista-de-ciclo

**Inputs:**
- Documento "Estado Cultural Atual"
- Tensões priorizadas
- Propósito e valores da marca/empresa
- Feedback de stakeholders sobre direção

**Ações:**
1. Workshop de thesis (4h): explorar candidatos a inimigo, sonho e mecanismo
2. Para cada tensão priorizada, formular versão de thesis completa
3. Testar coerência interna de cada candidata (4 perguntas de validação)
4. Selecionar 2-3 finalistas e refinar articulação
5. Produzir variações de expressão: 15seg, tweet, parágrafo, manifesto
6. Reescrever usando exclusivamente linguagem do público

**Outputs:**
- 2-3 thesis candidatas articuladas
- Variações de expressão por thesis
- Coerência interna documentada

**Decision Gate:**
- Pelo menos 1 thesis forte e coerente → avançar para Fase 3
- Nenhuma thesis convincente → workshop adicional ou revisitar sinais

### Fase 3: Validação e Stress Test (Semana 3)

**Agentes:** movement-architect, estrategista-de-ciclo, fenomenologo

**Inputs:**
- Thesis candidatas finalistas
- Counter-Narrative Playbook
- Inner circle de 10-20 membros
- Glossário de linguagem

**Ações:**
1. Testar thesis com inner circle: apresentar sem contexto de marca, observar reação
2. Coletar NPS de cada thesis candidata (1-10: "quanto isso ressoa com você?")
3. Stress test contra top 5 contra-narrativas: a thesis resiste?
4. Verificar se thesis funciona na linguagem do público (não apenas na linguagem do squad)
5. Selecionar thesis vencedora com base em: ressonância + coerência + resistência

**Outputs:**
- Thesis selecionada com scores de validação
- Resultados de stress test documentados
- Feedback do inner circle compilado

**Decision Gate:**
- NPS >= 8 e stress test aprovado → avançar para Fase 4
- NPS 6-7 → iterar thesis com feedback antes de avançar
- NPS < 6 → voltar para Fase 2

### Fase 4: Identidade Coletiva (Semanas 3-4)

**Agentes:** identitario, manifestador, movement-architect

**Inputs:**
- Thesis selecionada e validada
- Referências visuais e estéticas do público
- Audit de identidades concorrentes
- Preferências coletadas em entrevistas

**Ações:**
1. Definir arquétipos culturais do movimento (2-3)
2. Criar vocabulário identitário (como membros se chamam, nomeiam práticas)
3. Desenvolver códigos visuais (símbolo, paleta, tipografia, estilo)
4. Desenvolver códigos verbais (saudações, rally cries, hashtags)
5. Projetar códigos comportamentais e rituais-base
6. Testar reconhecibilidade ("na rua, como se reconhecem?")
7. Produzir Identity Kit v1.0 distribuível

**Outputs:**
- Identity System Document completo
- Cultural Code Cards (visual, verbal, comportamental, ritual)
- Identity Kit v1.0

**Decision Gate:**
- Teste de reconhecibilidade aprovado → avançar para Fase 5
- Identidade fraca → fortalecer códigos antes de lançar

### Fase 5: Aprovação e Lançamento Interno (Semana 4)

**Agentes:** movement-architect, estrategista-de-ciclo

**Inputs:**
- Thesis Document finalizado
- Identity System e Kit
- Feedback consolidado de validação

**Ações:**
1. Compilar Thesis Document formal com tudo: thesis + variações + evidências + guardrails
2. Apresentar para stakeholders: pitch de 20min + Q&A
3. Incorporar ajustes finais (se necessário)
4. Distribuir internamente para todo o squad e squads parceiros
5. Realizar sessão de imersão do squad na nova thesis
6. Publicar como "north star" para próximo trimestre

**Outputs:**
- Thesis Document v1.0 aprovado
- Identity Kit distribuído
- Squad alinhado
- Stakeholders aprovaram

**Decision Gate:**
- Aprovação obtida → iniciar workflows de criação e ativação
- Aprovação parcial → iterar pontos específicos e reaprovar

## Cadência

- **Ciclo completo:** 4 semanas (trimestral ou quando pivot necessário)
- **Semana 1:** Síntese de sinais
- **Semana 2:** Forja da thesis
- **Semana 3:** Validação + início de identidade
- **Semana 4:** Finalização de identidade + aprovação

## Artefatos Produzidos

- Documento "Estado Cultural Atual"
- Thesis Document v1.0 (Inimigo/Sonho/Mecanismo)
- Identity System Document
- Cultural Code Cards
- Identity Kit v1.0
- Decision Log com aprovações

## Métricas de Sucesso

| Métrica | Meta |
|---------|------|
| NPS da thesis com inner circle | >= 8/10 |
| Stress test contra-narrativas | 100% resistente |
| Validação com linguagem real | Aprovada |
| Teste de reconhecibilidade | Aprovado |
| Aprovação de stakeholders | Obtida em 1 rodada |
| Tempo de ciclo completo | <= 4 semanas |

### Regras de Fluxo
- **Quality Gate entre fases:** Fase 1→2: tensões claras e documentadas; Fase 2→3: pelo menos 1 thesis forte; Fase 3→4: NPS ≥ 8 e stress test aprovado; Fase 4→5: teste de reconhecibilidade aprovado
- **Rework:** Se thesis reprovada na validação → voltar para Fase 2 com feedback do inner circle
- **Escalation:** Se conflito com posicionamento da marca → escalar para Movement Chief e stakeholders
- **Handoff:** Thesis + Identity Kit aprovados alimentam → `workflows/02-artifact-foundry.md` e `workflows/03-activation-sprint.md`
