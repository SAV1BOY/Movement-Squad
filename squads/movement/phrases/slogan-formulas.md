# Fórmulas de Slogan para Movimentos

## Contexto de Uso

Slogans de movimento seguem padrões retóricos que podem ser sistematizados em fórmulas. Essas estruturas permitem gerar variações rapidamente. Use como ferramenta de brainstorm, referência para sessões de naming e base para testes A/B de mensagem.

## Frases

### Fórmula: [Verbo] + [Objeto]

- "Quebre o padrão." / "Reescreva as regras." / "Construa o futuro."
- "Desafie o óbvio." / "Mova o impossível." / "Liberte a ideia."
- "Acenda a revolução." / "Plante a semente." / "Vire a mesa."
- "Abra o caminho." / "Cruze a fronteira." / "Mude a conversa."
- "Comece o movimento." / "Lidere a mudança." / "Faça história."
- **Dica:** verbos de ação física (quebrar, mover, acender) criam mais energia que verbos abstratos.

### Fórmula: [Nós] vs [Eles]

- "Nós criamos. Eles copiam." / "Nós construímos. Eles comentam."
- "Enquanto eles esperam, nós fazemos." / "Eles falam. Nós entregamos."
- "Eles seguem tendências. Nós criamos as nossas."
- "Eles medem cliques. Nós medimos impacto."
- "Eles vendem promessas. Nós mostramos resultados."
- **Dica:** use com moderação — polarização extrema pode alienar. O "eles" deve ser um comportamento, não um grupo.

### Fórmula: [Para quem] + [Verbo]

- "Para quem não aceita o medíocre." / "Para quem escolhe construir."
- "Para os que se recusam a ficar parados." / "Para quem quer mais do que likes."
- "Para os inconformados. Para os criadores. Para os que agem."
- "Para quem sabe que pertencer é mais valioso que possuir."
- **Dica:** essa fórmula funciona como filtro de audiência — atrai quem se identifica.

### Fórmula: [Negação] + [Afirmação]

- "Não é marketing. É movimento." / "Não é produto. É propósito."
- "Não é sobre nós. É sobre vocês." / "Não é um grupo. É uma família."
- "Não é tendência. É convicção." / "Não é hype. É história."
- "Não esperamos aprovação. Criamos nossa própria."
- **Dica:** a negação cria contraste instantâneo; a afirmação entrega a promessa.

### Fórmula: [Número/Ritmo] + [Impacto]

- "Um movimento. Mil vozes. Zero desculpas."
- "Três palavras: construir, juntos, agora."
- "100% transparência. 0% bullshit."
- "Uma comunidade. Uma missão. Sem volta."
- **Dica:** números e ritmo ternário criam memorabilidade sonora.

## Dicas de Aplicação

- **Brainstorm:** preencha cada fórmula com 10 variações; selecione as 3 melhores.
- **Teste de voz:** leia em voz alta — se não soa natural, reescreva.
- **Comprimento:** slogans de movimento ideais têm 3 a 7 palavras.
- **Unicidade:** verifique se o slogan não existe em outra marca antes de adotar.
- **Multi-formato:** o mesmo slogan deve funcionar em bio, camiseta, hashtag e outdoor.
- **Iteração:** slogans evoluem com o movimento. Revise a cada fase de crescimento.
