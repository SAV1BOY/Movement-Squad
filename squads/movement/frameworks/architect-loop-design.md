# Loop Design

## Overview

Movimentos crescem por loops, não por empurrões. Um empurrão é uma campanha: você investe energia e ela se dissipa. Um loop é um sistema: a energia circula e se amplifica sozinha. Este framework ensina o Architect a projetar loops de retroalimentação que fazem o movimento crescer de forma orgânica e sustentável.

O loop fundamental de um movimento é: sinal → tese → artefato → distribuição → prova → mais sinais. Se qualquer elo quebra, o loop para.

## Princípios

1. **Loops são o produto** — O trabalho do Architect não é criar peças isoladas. É criar loops que funcionam sem supervisão constante.

2. **Cada loop precisa de combustível** — O combustível é atenção, emoção ou incentivo. Sem combustível, o loop para mesmo que a mecânica esteja perfeita.

3. **Simplicidade no design, complexidade no resultado** — Os melhores loops têm 3-5 etapas. Mais que isso e a probabilidade de quebra cresce exponencialmente.

4. **Loops quebrados são prioridade número 1** — Um loop quebrado é pior que nenhum loop. Ele consome energia sem retorno. Identifique e conserte ou elimine.

5. **Teste cada elo separadamente** — Antes de rodar o loop completo, teste cada transição isoladamente. A→B funciona? B→C funciona?

6. **Loops compostos vencem** — Quando dois loops se conectam, o crescimento é exponencial. Busque pontos de conexão entre loops.

## Protocolo

### Passo 1: Identificar o Loop Central

1. Defina o loop principal do movimento em 4-6 etapas.
2. Cada etapa deve responder: "o que acontece aqui?" e "o que faz a pessoa ir para a próxima etapa?"
3. A última etapa deve alimentar a primeira (fechando o ciclo).

**Exemplo de loop central:**
- Pessoa vê artefato → sente identificação → compartilha → novo público vê → parte adere → adepto cria conteúdo → conteúdo vira novo artefato.

### Passo 2: Mapear Combustível de Cada Elo

4. Para cada transição entre etapas, identifique o combustível:
   - **Emocional**: raiva, orgulho, pertencimento, indignação.
   - **Social**: status, reconhecimento, validação do grupo.
   - **Prático**: utilidade, benefício tangível, acesso exclusivo.
5. Se não há combustível claro em uma transição, o loop vai travar ali.

### Passo 3: Testar Cada Transição

6. Teste A→B: crie o artefato e meça se gera identificação (comentários qualitativos).
7. Teste B→C: meça se a identificação gera compartilhamento (taxa de share).
8. Teste C→D: meça se o compartilhamento traz público novo (novos seguidores/visitantes).
9. Continue testando cada elo. O elo mais fraco define a força do loop inteiro.

### Passo 4: Identificar e Corrigir Quebras

10. Sinais de loop quebrado:
    - Métricas caem consistentemente em uma etapa específica.
    - Energia manual necessária para manter o fluxo (a squad "empurra" em vez do loop puxar).
    - UGC para de aparecer mesmo com artefatos novos.
11. Para cada quebra, pergunte: "o combustível acabou ou a mecânica está errada?"
12. Combustível acabou → mude o tipo de combustível ou intensifique o existente.
13. Mecânica errada → simplifique a transição ou remova a etapa problemática.

### Passo 5: Projetar Loops Secundários

14. Loops secundários amplificam o loop central. Exemplos:
    - **Loop de champions**: membro ativo → reconhecimento público → status → mais atividade.
    - **Loop de conteúdo**: UGC → curadoria pela marca → visibilidade para o criador → mais UGC.
    - **Loop de dados**: métrica → insight → artefato melhor → métrica melhor.
15. Conecte loops secundários ao loop central em pontos estratégicos.

### Passo 6: Monitorar Saúde dos Loops

16. Defina uma métrica para cada elo do loop.
17. Crie um dashboard simples que mostra o "funil" do loop (quantas pessoas entram em cada etapa).
18. Revisão semanal: o loop está acelerando, estável ou desacelerando?
19. Se desacelerando por 2 semanas consecutivas, intervenção obrigatória.

## Quando Usar

- Ao projetar a arquitetura de um novo movimento.
- Quando o crescimento orgânico trava sem razão aparente.
- Para diagnosticar por que UGC parou de aparecer.
- Ao integrar um novo canal ou artefato ao sistema existente.

## Quando Não Usar

- Para problemas de conteúdo/tom — use os frameworks do Manifestor.
- Se o problema é falta de audiência inicial — loops precisam de massa mínima para funcionar.
- Para planejamento de calendário — use o framework do Cycle.

## Integração

- **Chief** aprova os loops projetados e aloca recursos para construí-los.
- **Manifestor** produz os artefatos que alimentam cada loop.
- **Phenomenology** identifica os combustíveis emocionais corretos.
- **Identity** garante que cada loop reforça a identidade coletiva.
- **Impact** monitora as métricas de cada elo do loop.
- **Cycle** sincroniza a cadência dos loops com o calendário de atenção.

## Exemplo Aplicado

**Contexto:** Movimento #CozinhaSemReceita de uma marca de utensílios de cozinha.

**Loop central projetado:**

```
[1. Vídeo provocativo] → "Receita é muleta. Cozinhar de verdade é sentir."
        ↓ (combustível: orgulho + identificação)
[2. Cozinheiro amador se identifica] → comenta "eu sempre cozinhei assim!"
        ↓ (combustível: validação social)
[3. Compartilha com amigos] → "olha, finalmente alguém falou isso"
        ↓ (combustível: status de early adopter)
[4. Novo público descobre] → vê vídeo + comentários como prova social
        ↓ (combustível: curiosidade + pertencimento)
[5. Parte adere e posta seu prato "sem receita"] → #CozinhaSemReceita
        ↓ (combustível: reconhecimento pela marca)
[6. Marca faz curadoria e reposta os melhores] → criador ganha visibilidade
        ↓ (alimenta etapa 1: UGC vira novo artefato)
```

**Testes por elo:**
- Elo 1→2: 340 comentários qualitativos em 48h. Funcionando.
- Elo 2→3: taxa de share de 4.2%. Acima da média. Funcionando.
- Elo 3→4: 1.200 novos seguidores por semana. Funcionando.
- Elo 4→5: apenas 12 posts com hashtag em 30 dias. QUEBRADO.
- Elo 5→6: não aplicável enquanto elo 4→5 não funcionar.

**Diagnóstico:** O combustível do elo 4→5 é fraco. Pessoas aderem mas não postam. Barreira: medo de julgamento ("e se meu prato for feio?").

**Correção:** Criar subartefato "prato feio com orgulho" — normalizar a imperfeição. Adicionar stories da equipe mostrando pratos "fracassados" com humor.

**Resultado após correção:** Posts com hashtag subiram de 12 para 87 em 30 dias. Loop restaurado.
