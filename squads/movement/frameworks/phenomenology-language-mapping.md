# Language Mapping

## Overview

Movimentos falam a língua do povo, não a língua do marketing. Este framework ensina o agente de Phenomenology a mapear a linguagem real do público-alvo: as palavras exatas, metáforas, expressões, gírias e frames que as pessoas usam quando falam sobre o tema do movimento. O resultado é um banco de linguagem organizado por emoção e contexto, que o Manifestor usa para criar artefatos que soam autênticos.

Se o público diz "estou no limite" e o manifesto diz "esgotamento profissional", há desconexão fatal.

## Princípios

1. **Verbatim é sagrado** — A palavra exata que a pessoa usou tem poder. Não parafraseie, não "melhore", não torne mais "profissional". Capture como foi dito.

2. **Contexto dá significado** — A mesma palavra muda de significado em contextos diferentes. "Correria" pode ser orgulho (empreendedor) ou exaustão (CLT). Registre o contexto.

3. **Metáforas revelam crenças** — Quando alguém diz "sou um hamster na roda", está revelando uma crença sobre como o sistema funciona. Metáforas são ouro.

4. **Frequência indica norma** — Se 80% do público usa "burnout" em vez de "esgotamento", o movimento usa "burnout". Não force vocabulário.

5. **Lacunas são oportunidades** — Se o público não tem palavra para algo que sente, criar essa palavra é uma das funções mais poderosas de um movimento.

6. **A linguagem evolui** — O mapa precisa ser atualizado. Gírias mudam, memes morrem, novas expressões surgem. Revisão trimestral mínima.

## Protocolo

### Passo 1: Definir o Território Linguístico

1. Determinar o tema central para mapeamento (alinhado com a tese do movimento).
2. Definir 3-5 contextos de captura:
   - Como falam sobre o problema.
   - Como falam sobre a solução desejada.
   - Como falam sobre si mesmos em relação ao tema.
   - Como falam sobre o "inimigo" (sistema, instituição, comportamento).
   - Como falam quando estão entre pares (vs. quando falam publicamente).

### Passo 2: Coletar Linguagem

3. Fontes primárias (linguagem espontânea):
   - Comentários em redes sociais (Twitter, Instagram, TikTok).
   - Threads de desabafo em fóruns (Reddit, grupos de Facebook).
   - Reviews e reclamações (Google, Reclame Aqui, app stores).
   - DMs e mensagens de comunidades (com permissão ou anonimizadas).

4. Fontes secundárias (linguagem provocada):
   - Entrevistas e conversas diretas.
   - Respostas a enquetes e caixinhas de perguntas.
   - Comentários em conteúdos da própria marca.

5. Meta: 100+ expressões capturadas, com fonte e contexto.

### Passo 3: Organizar o Banco de Linguagem

6. Criar banco com as seguintes categorias:

**Por emoção:**
- Raiva: expressões de frustração, indignação, revolta.
- Medo: expressões de ansiedade, insegurança, vulnerabilidade.
- Orgulho: expressões de conquista, identidade, pertencimento.
- Desejo: expressões de aspiração, sonho, mudança.
- Humor: piadas, ironias, sarcasmo sobre o tema.

**Por função:**
- Diagnóstico: como descrevem o problema ("o sistema é...").
- Identidade: como se descrevem ("eu sou alguém que...").
- Ação: como falam sobre agir ("precisamos...", "chega de...").
- Prova: como falam sobre evidências ("olha o que aconteceu...").

7. Para cada expressão, registrar: verbatim exato, fonte, contexto, emoção, frequência (rara/moderada/comum).

### Passo 4: Identificar Padrões Linguísticos

8. **Metáforas recorrentes**: quais imagens o público usa repetidamente? (ex: "roda de hamster", "jogo de cartas marcadas", "tapa na cara").
9. **Frames dominantes**: como o público enquadra a questão? (ex: "saúde vs. doença", "liberdade vs. prisão", "justiça vs. exploração").
10. **Palavras-gatilho**: quais palavras geram reação imediata (positiva ou negativa)?
11. **Lacunas linguísticas**: há algo que o público sente mas não tem palavra para expressar?

### Passo 5: Criar Glossário do Movimento

12. Selecionar as 15-20 expressões mais poderosas do banco.
13. Criar glossário para uso do Manifestor com:
    - Expressão.
    - Quando usar (contexto recomendado).
    - Quando não usar (risco de desconexão).
    - Exemplo de uso em artefato.

14. Se houver lacuna linguística, propor neologismo ou expressão nova que o movimento pode popularizar.

### Passo 6: Validar e Iterar

15. Testar as expressões em artefatos reais e medir ressonância.
16. Expressões com alta ressonância sobem na prioridade.
17. Expressões que não performam são reavaliadas (contexto errado ou linguagem mudou?).
18. Atualizar o banco a cada 60-90 dias.

## Quando Usar

- No início de um movimento para calibrar a voz dos artefatos.
- Quando artefatos "não soam como o público fala".
- Para onboarding de novos criadores de conteúdo na squad.
- A cada trimestre como atualização linguística.

## Quando Não Usar

- Para definir a tese do movimento — use Signal Clustering.
- Para medir performance — use os frameworks do Impact.
- Se o público-alvo mudou significativamente — refaça a etnografia primeiro.

## Integração

- **Manifestor** é o principal consumidor deste mapa — usa como referência para todo artefato.
- **Identity** usa as expressões de identidade para construir o "nós".
- **Chief** valida que a linguagem está alinhada com o posicionamento estratégico.
- **Architect** usa os patterns linguísticos para projetar loops de engajamento.
- **Cycle** identifica linguagem sazonal ou temporal.
- **Impact** mede quais expressões geram mais ressonância em artefatos.

## Exemplo Aplicado

**Contexto:** Mapeamento linguístico para movimento sobre finanças pessoais para jovens.

**Banco de linguagem (amostra):**

| Verbatim | Emoção | Contexto | Frequência |
|----------|--------|----------|------------|
| "Tô sempre no vermelho" | Frustração | Descreve situação financeira | Comum |
| "Ninguém me ensinou isso na escola" | Raiva | Falta de educação financeira | Muito comum |
| "Me sinto burro com dinheiro" | Vergonha | Entre pares, confissão | Moderada |
| "Investimento é coisa de rico" | Resignação | Quando vê conteúdo de finanças | Comum |
| "Dinheiro é tabu na minha família" | Desconforto | Contexto familiar | Moderada |
| "Eu só quero parar de dever" | Desejo | Aspiração básica | Muito comum |
| "Os gurus de finanças são de outro planeta" | Distância | Crítica a influencers | Comum |

**Metáforas recorrentes:**
- "Estou afogado" (dívida como água).
- "É um buraco sem fundo" (dívida como abismo).
- "Vivo apagando incêndio" (finança como emergência constante).

**Lacuna identificada:** Não há palavra para "a vergonha de não saber lidar com dinheiro". Oportunidade: criar o termo "analfabetismo financeiro forçado" — coloca a culpa no sistema, não na pessoa.

**Glossário para o Manifestor (top 5):**
1. "Ninguém me ensinou" — usar em provocações sobre o sistema educacional.
2. "Parar de dever" — usar em conteúdo aspiracional acessível.
3. "Gurus de outro planeta" — usar para se diferenciar de influencers financeiros.
4. "Apagando incêndio" — usar para descrever o dia-a-dia com empatia.
5. "Analfabetismo financeiro forçado" — usar como conceito central do movimento.
