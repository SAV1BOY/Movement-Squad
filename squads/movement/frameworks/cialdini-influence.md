# Cialdini — Influence

## Overview

Robert Cialdini identificou seis princípios universais de persuasão — atalhos psicológicos que guiam decisões humanas. Esses princípios operam de forma automática e são poderosos tanto para o bem quanto para manipulação. No contexto de movimentos, devem ser usados **eticamente** para facilitar adesão genuína, nunca para enganar.

### Os 6 Princípios:

1. **Reciprocidade**: quando alguém nos dá algo, sentimos obrigação de retribuir. Dar primeiro, sem pedir nada, gera dívida social.
2. **Compromisso e Consistência**: uma vez que tomamos uma posição pública ou fazemos um pequeno compromisso, tendemos a manter consistência com essa posição.
3. **Prova Social**: em situações de incerteza, olhamos para o que outros fazem. Quanto mais "gente como nós" faz algo, mais queremos fazer.
4. **Autoridade**: seguimos pessoas com expertise, credenciais ou posição de autoridade percebida.
5. **Afeição (Liking)**: dizemos sim a pessoas de quem gostamos. Similaridade, elogios, cooperação e familiaridade geram afeição.
6. **Escassez**: valorizamos mais o que é raro ou está acabando. Medo de perder (FOMO) é mais motivador que desejo de ganhar.

## Princípios Aplicáveis ao MMOS

1. **Reciprocidade como porta de entrada**. O movimento deve dar valor antes de pedir engajamento — conteúdo gratuito, ferramentas, comunidade.
2. **Micro-compromissos escalonam adesão**. Comece com ações pequenas (seguir, curtir) antes de pedir grandes (participar, evangelizar).
3. **Prova social é o acelerador**. Mostrar quantos participam, quem participa, e depoimentos de membros.
4. **Autoridade subcultural**. No movimento, autoridade vem de expertise vivida, não de títulos corporativos.
5. **Escassez com integridade**. Edições limitadas, acessos antecipados — mas nunca falsa escassez.
6. **Afeição via identidade compartilhada**. "Somos parecidos" é mais persuasivo que "somos melhores".

## Protocolo de Aplicação

### Passo 1 — Mapear a Jornada de Adesão com os 6 Princípios
Para cada etapa da jornada do membro, identifique qual princípio ativar:

| Etapa da Jornada    | Princípio Principal | Tática                                    |
|----------------------|--------------------|--------------------------------------------|
| Descoberta           | Prova Social       | "X pessoas já fazem parte"                 |
| Primeiro contato     | Reciprocidade      | Dar algo valioso sem pedir nada             |
| Consideração         | Autoridade         | Mostrar expertise/credenciais do movimento  |
| Adesão inicial       | Compromisso        | Pedir micro-ação pública (postar, assinar)  |
| Engajamento profundo | Consistência       | Lembrar compromissos anteriores             |
| Evangelização        | Afeição            | Criar senso de "nós" que gera desejo de incluir|

### Passo 2 — Design de Reciprocidade
- O que o movimento dá de graça antes de pedir qualquer coisa?
- Exemplos: template gratuito, acesso a comunidade, conteúdo exclusivo, ferramenta.
- Regra: o valor dado deve ser real e suficiente por si só (não isca com pegadinha).

### Passo 3 — Escada de Compromisso
Projete uma sequência de compromissos crescentes:
1. Seguir nas redes (esforço mínimo).
2. Baixar um recurso gratuito (troca de e-mail).
3. Participar de evento aberto (investimento de tempo).
4. Postar publicamente sobre o movimento (compromisso público).
5. Convidar alguém (evangelização).
6. Assumir papel de liderança (compromisso máximo).

Cada degrau aumenta a consistência e reduz a chance de desistência.

### Passo 4 — Construir Prova Social Estratégica
- Números: "Já somos X membros" (mas só se o número for significativo).
- Depoimentos: "Gente como você" fazendo parte (similaridade > celebridade).
- Visibilidade: badges, frames, hashtags que mostram pertencimento.
- Comportamento visível: "85% dos nossos membros fizeram X" (norma descritiva).

### Passo 5 — Audit Ético
Para cada aplicação dos princípios, pergunte:
- Estamos facilitando uma decisão que a pessoa tomaria conscientemente? ✅
- Estamos manipulando para uma decisão que prejudica a pessoa? ❌
- A escassez é real ou fabricada? Deve ser real.
- A prova social é genuína ou inflada? Deve ser genuína.

## Quando Usar / Não Usar

### Usar quando:
- Projetando a jornada de adesão ao movimento (funil de engajamento).
- Criando landing pages, CTAs, convites, onboarding.
- Otimizando taxas de conversão em cada etapa.
- Treinando embaixadores sobre como convidar novos membros.

### Não usar quando:
- A aplicação envolve manipulação ou falsa representação.
- O público-alvo é vulnerável e pode ser explorado.
- Estamos na fase de pesquisa (Radar) — ainda não há jornada para otimizar.
- O movimento prioriza profundidade sobre conversão (Ganz e Godin são melhores).

## Exemplo Aplicado

### Caso: Movimento de código aberto para desenvolvedores brasileiros

**Reciprocidade**: o movimento oferece biblioteca open-source de alta qualidade + documentação em português. Valor real, sem pedir nada.

**Compromisso escalonado**:
1. Dar star no GitHub (1 segundo).
2. Usar a biblioteca num projeto (investimento técnico).
3. Reportar bug (contribuição pública).
4. Submeter pull request (compromisso visível).
5. Mentorear novos contribuidores (liderança).

**Prova social**: "Usado por X empresas brasileiras" + logos no README. Depoimentos de devs que avançaram na carreira contribuindo.

**Autoridade**: mantenedores com perfil público forte (palestras, artigos). Código de alta qualidade que demonstra expertise.

**Afeição**: "Feito por devs brasileiros, para devs brasileiros." Similaridade gera conexão.

**Escassez ética**: vagas limitadas para programa de mentoria (real — cada mentor atende máx. 3 pessoas). Acesso antecipado a novas features para contribuidores ativos.

**Métrica**: taxa de progressão na escada de compromisso. Meta: 10% de quem dá star chega a reportar bug em 6 meses.
