# Platform Dynamics — Dinâmicas de Plataforma

## O que é este diretório

Aqui documentamos as dinâmicas específicas de cada plataforma onde o
movimento opera. Cada plataforma tem sua própria cultura, algoritmo,
formatos e regras não-escritas que afetam como um movimento se propaga.

## Por que mapeamos dinâmicas de plataforma

O mesmo conteúdo performa de forma radicalmente diferente dependendo da
plataforma. Entender as dinâmicas de cada uma nos permite adaptar a
estratégia sem perder a essência do movimento.

## O que colocar aqui

- **Perfis de plataforma**: como cada plataforma funciona para movimentos
- **Mudanças de algoritmo**: atualizações que afetam distribuição
- **Formatos emergentes**: novos formatos que ganham tração
- **Cultura de plataforma**: normas, linguagem e expectativas do público
- **Casos de estudo**: exemplos de movimentos que cresceram em cada plataforma
- **Riscos de plataforma**: mudanças que podem ameaçar a estratégia

## Formato sugerido

Nomeie como `YYYY-MM-DD_plataforma_aspecto.md`.
Exemplo: `2026-03-10_linkedin_mudanca-algoritmo-video.md`

Cada documento deve conter:
- Plataforma analisada
- Aspecto específico documentado
- Evidências e dados observados
- Impacto na estratégia do movimento
- Recomendações de adaptação
- Data de validade estimada (dinâmicas mudam rápido)

## Plataformas prioritárias

Mantenha pelo menos um perfil atualizado para cada plataforma onde
o movimento está ativo. Priorize por relevância para o público-alvo.

## Quem alimenta

O **Anthropologist Agent** monitora mudanças, o **Memetic Engineer**
testa formatos e o **Distribution Hacker** otimiza distribuição.

## Cadência

- Monitoramento contínuo de mudanças de algoritmo
- Perfil de plataforma atualizado trimestralmente
- Alertas imediatos para mudanças significativas
