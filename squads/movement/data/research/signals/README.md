# Signals — Capturas de Sinais Culturais

## O que é este diretório

Este diretório armazena capturas diárias e semanais de sinais culturais relevantes
para o movimento. Sinais são fragmentos do mundo real — frases, comportamentos,
memes, notícias, mudanças de linguagem — que indicam para onde a cultura está se
movendo.

## Por que capturamos sinais

Movimentos não nascem do nada. Eles surfam ondas culturais que já existem.
Capturar sinais sistematicamente nos permite:

- Identificar tensões culturais antes que virem mainstream
- Validar ou invalidar hipóteses de movimento
- Alimentar o trabalho de criação de narrativas e conteúdo
- Detectar mudanças de sentimento no público-alvo

## O que colocar aqui

- **Capturas diárias**: prints, links, transcrições de conversas públicas
- **Resumos semanais**: consolidação dos sinais mais relevantes da semana
- **Sinais de plataforma**: mudanças de algoritmo, novos formatos, trends
- **Sinais de mercado**: movimentos de concorrentes, notícias do setor
- **Sinais de comunidade**: mudanças de linguagem, novos termos, tensões

## Formato sugerido

Use o padrão `YYYY-MM-DD_tipo_descricao-curta.md` para nomear arquivos.
Exemplo: `2026-03-10_diario_tensao-produtividade-toxica.md`

Cada arquivo deve conter:
- Data e hora da captura
- Fonte (plataforma, perfil, contexto)
- Descrição do sinal
- Interpretação inicial (o que isso pode significar)
- Tags relevantes

## Quem alimenta

Principalmente o **Anthropologist Agent**, mas qualquer membro do squad pode
adicionar sinais. O Chief of Movement revisa semanalmente para priorizar
os sinais mais relevantes para a estratégia.

## Cadência

- Captura diária (mínimo 3 sinais por dia útil)
- Consolidação semanal (todo domingo ou segunda)
- Revisão mensal para arquivamento (mover para `signal-archive.yaml`)
