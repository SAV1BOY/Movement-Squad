# Construtor de Revisão Trimestral

## Propósito

Construir revisão trimestral do movimento — o relatório mais completo e
estratégico do ciclo. Avalia desempenho, extrai aprendizados e define
direção para o próximo trimestre.

## Template

### Resumo Executivo (1 página)

```
REVISÃO TRIMESTRAL — [Movimento] — [Q_ 20__]
HEALTH SCORE: [X.X/10] (anterior: [X.X]) [↑↓→]

1. [Conquista mais importante]
2. [Desafio mais relevante]
3. [Direção para próximo trimestre]
```

### Objetivos

| Objetivo     | Target | Resultado | Status                    |
|-------------|--------|-----------|---------------------------|
| [objetivo]  | [meta] | [real]    | [superou/atingiu/parcial/falhou] |

### Métricas Consolidadas

```
              Q Atual  Q Anterior  Variação
Alcance:      [n]      [n]         [+/-X%]
Engajamento:  [X%]     [X%]        [+/-X pp]
MAU:          [n]      [n]         [+/-X%]
Retenção D30: [X%]     [X%]        [+/-X pp]
Net Sentiment:[X%]     [X%]        [+/-X pp]
UGC gerado:   [n]      [n]         [+/-X%]
Champions:    [n]      [n]         [+/-X%]
```

### Aprendizados (Top 5)

```
1. [Aprendizado] — Evidência: [...] — Implicação: [...]
2. [...]
```

### Destaques

```
CONQUISTAS: 1.[...] 2.[...] 3.[...]
TOP CONTEÚDO: 1.[peça]—[canal]—[métricas]—[por que funcionou]
RECONHECIMENTOS: [pessoa] por [contribuição]
```

### Desafios e Riscos

```
DESAFIOS: 1.[desafio]—[como lidamos]—[status]
RISCOS Q+1: 1.[risco]—[probabilidade]—[mitigação]
```

### Plano Próximo Trimestre

```
OBJETIVOS: 1.[objetivo]—[métrica]—[target]
INICIATIVAS: 1.[iniciativa]—[responsável]—[timeline]
RECURSOS: [recurso]—[justificativa]
```

## Processo

| Semana | Atividade                                    |
|--------|----------------------------------------------|
| -2     | Coletar métricas, rodar health score         |
| -1     | Analisar, sessão de aprendizados com time    |
| 0      | Redigir relatório, revisar                   |
| +1     | Apresentar para stakeholders                 |

## Dicas

- C-level: 3 pág. Gestão: 10 pág. Time: 5 pág. Comunidade: 1 pág.
- Máximo 10 páginas. Gráficos > tabelas
- Honestidade sobre falhas gera confiança
