# Carta de Identidade do Movimento

## Instruções de Uso

A Carta de Identidade é o documento que define quem somos como grupo — nossa linguagem,
símbolos, códigos e fronteiras. Diferente de um brand book, ela é feita para ser
apropriada e vivida pelos membros, não apenas pela equipe de marketing.

**Quando usar:** Após tese aprovada, como base para manifesto e todos os materiais.
**Quem preenche:** Estrategista + diretor criativo + input da comunidade.
**Documento vivo:** Atualizar a cada trimestre com input dos membros.

## Exemplo Preenchido

### Quem Somos
**Declaração:** Somos os que param pra ler. Os que questionam o óbvio. Os que escolhem saber.
**Valores:** 1) Transparência radical, 2) Acessibilidade (não elitismo), 3) Ação coletiva.
**Reconhecimento:** Usamos o emoji de lupa nos posts. Compartilhamos fotos de rótulos.

### O Que Combatemos
**Eles:** A lógica de marketing que prioriza embalagem sobre ingrediente.
**Não é:** Os funcionários das empresas, pessoas que compram ultraprocessados.
**Tom:** Indignação com o sistema, empatia com as pessoas.

### Linguagem
**Vocabulário:** "Rótulo real" (ingredientes honestos), "Teatro da saúde" (marketing enganoso).
**Expressões:** "Leu o rótulo?", "Ingrediente que vó conhece", "Comida não precisa de propaganda."

## Dicas

- **Identidade é inclusiva na entrada, exigente nos valores.** Facilite aderir, mas não aceite tudo.
- **Símbolos simples escalam.** Se precisa explicar, é complicado demais.
- **A linguagem surge do público.** Observe como eles falam antes de definir termos.
- **"Eles" nunca é demográfico.** É sempre uma mentalidade, prática ou sistema.
- **Atualize com a comunidade.** A carta deve evoluir com input real dos membros.
