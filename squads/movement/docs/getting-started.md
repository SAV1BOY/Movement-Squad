# Getting Started — Como Começar com o Movement Squad

## Bem-vindo ao Movement Squad

Este guia vai te orientar nos primeiros passos para trabalhar com o Movement
Squad. Se você acabou de chegar, comece por aqui.

## O que é o Movement Squad?

O Movement Squad é uma equipe especializada em construir movimentos — não
campanhas de marketing. Movimentos são maiores que produtos ou marcas.
Eles mudam como as pessoas pensam, agem e se identificam.

Para entender a diferença entre movimento e marketing tradicional, leia o
`movement-vs-marketing-guide.md` depois de terminar este documento.

## Pré-requisitos

Antes de começar, certifique-se de:
1. Ter acesso ao repositório do Movement Squad
2. Ler o `squad-overview.md` para entender a filosofia
3. Conhecer os 7 agentes em `agent-roles-guide.md`
4. Ter clareza sobre seu papel no squad

## Primeiros Passos

### Passo 1: Entenda a Estrutura
```
squads/movement/
├── agents/          → Definições dos 7 agentes
├── checklists/      → Checklists operacionais
├── data/            → Dados, pesquisa, registros, métricas
├── docs/            → Documentação (você está aqui)
├── frameworks/      → Frameworks estratégicos
├── templates/       → Templates reutilizáveis
└── workflows/       → Fluxos de trabalho
```

### Passo 2: Leia os Documentos Essenciais
Na seguinte ordem:
1. `squad-overview.md` — O que somos e por quê existimos
2. `agent-roles-guide.md` — Quem faz o quê
3. `operating-system.md` — Como operamos no dia a dia
4. `workflow-guide.md` — Como executar os fluxos de trabalho
5. `ethics-and-boundaries-guide.md` — O que nunca fazemos

### Passo 3: Familiarize-se com os Dados
Explore o diretório `data/` para entender:
- `data/research/` — Pesquisa e sinais culturais
- `data/registries/` — Registros operacionais (teses, champions, etc.)
- `data/metrics/` — Definições de métricas

### Passo 4: Conheça os Frameworks
Os frameworks são ferramentas de pensamento. Leia o
`framework-selection-guide.md` para saber quando usar cada um.

### Passo 5: Pratique com Templates
Templates são pontos de partida para deliverables. Veja o
`template-usage-guide.md` para aprender a usá-los.

## Erros Comuns de Quem Começa

- **Achar que é marketing com nome bonito** — Não é. Leia o
  `movement-vs-marketing-guide.md`
- **Querer resultados em 2 semanas** — Movimentos levam meses para ganhar
  tração. Paciência é parte do processo
- **Ignorar pesquisa** — Nunca pule a fase de pesquisa. Sinais e etnografia
  são a base de tudo
- **Copiar outro movimento** — Autenticidade é inegociável. Inspire-se,
  mas nunca copie
