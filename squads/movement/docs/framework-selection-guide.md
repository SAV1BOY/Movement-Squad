# Framework Selection Guide — Como Escolher Frameworks

## Visão Geral

O Movement Squad utiliza diversos frameworks para estruturar pensamento e
decisão. Este guia ajuda a escolher o framework certo para cada situação.
Frameworks são ferramentas — use o certo para o problema certo.

## Princípio Fundamental

Nenhum framework é universal. Cada um ilumina certos aspectos e deixa
outros no escuro. A habilidade está em saber qual usar e quando.

## Matriz de Seleção

## Como Avaliar se Está Usando o Framework Certo

Sinais de que está no framework errado:
- O framework não responde a pergunta que você tem
- Você está forçando informação em campos que não fazem sentido
- O output do framework não é acionável
- O time não entende o output

Sinais de que está no framework certo:
- O processo de preencher já gera insights
- O output é claro e acionável
- O time consegue usar o output diretamente
- A decisão fica mais fácil depois de usar o framework

## Combinando Frameworks

Muitas situações pedem mais de um framework. Combinações comuns:

1. **Estratégia + Narrativa**: Movement Thesis Canvas → Story Architecture
2. **Pesquisa + Comunidade**: Ethnographic Notes → Community Architecture
3. **Conteúdo + Métricas**: Content-to-Conversation → Memetic Spread Model
4. **Experimento + Decisão**: Experiment Design → Decision Log

## Quando NÃO Usar Framework

- Quando a situação é simples e a resposta é óbvia
- Quando velocidade é mais importante que estrutura
- Quando nenhum framework existente se encaixa (crie um novo)
- Quando o time já tem consenso sobre o caminho

## Onde Encontrar os Frameworks

Frameworks detalhados ficam em `squads/movement/frameworks/`. Cada framework
é um arquivo com estrutura, instruções e exemplos de uso.
