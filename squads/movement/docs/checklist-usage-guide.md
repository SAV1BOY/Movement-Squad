# Checklist Usage Guide — Como Usar Checklists

## Visão Geral

Checklists são listas de verificação que garantem que nada importante seja
esquecido durante a execução de tarefas. Diferente de workflows (que guiam
o processo), checklists validam o resultado.

## Por que Usamos Checklists

Até os melhores profissionais esquecem coisas. Checklists existem porque:
- Tarefas repetitivas geram complacência
- Detalhes pequenos fazem diferença grande
- Pressão de tempo causa atalhos perigosos
- Consistência de qualidade é inegociável

## Como Usar

### Antes de Começar
1. Identifique qual checklist se aplica à tarefa
2. Leia a checklist inteira antes de começar a trabalhar
3. Se algum item não se aplica, marque como "N/A" (nunca delete)

### Durante a Execução
1. Use a checklist como referência, não como restrição
2. Marque itens conforme for completando
3. Se descobrir que falta algo na checklist, anote para sugerir depois

### Depois de Concluir
1. Revise todos os itens — nenhum deve ficar sem marcar ou explicar
2. Se algum item ficou "N/A", documente o porquê brevemente
3. Entregue o deliverable com a checklist preenchida como anexo

## Checklists Disponíveis

### Checklists de Qualidade
- **Review de Conteúdo**: Verificar antes de publicar qualquer conteúdo
- **Review de Narrativa**: Garantir coerência narrativa
- **Review de Dados**: Validar dados antes de apresentar

### Checklists Operacionais
- **Novo Membro**: Passos de onboarding
- **Novo Champion**: Ativação de champion
- **Novo Experimento**: Validar design antes de lançar
- **Novo Ritual**: Garantir que ritual está pronto para lançar

### Checklists de Publicação
- **Post LinkedIn**: Verificar antes de publicar no LinkedIn
- **Newsletter**: Verificar antes de enviar newsletter
- **Manifesto**: Verificar antes de lançar manifesto

### Checklists Estratégicas
- **Nova Tese**: Validar completude da tese
- **Decisão Estratégica**: Verificar que todas as alternativas foram consideradas
- **Expansão de Plataforma**: Readiness check antes de ir para nova plataforma

## Onde Encontrar

Checklists ficam em `squads/movement/checklists/`. Cada checklist é um
arquivo com itens numerados e campos para marcação.

## Formato de uma Checklist

```
# [Nome da Checklist]
Data: ___________
Responsável: ___________
Deliverable: ___________

## Itens
- [ ] Item 1: Descrição clara do que verificar
- [ ] Item 2: Descrição clara do que verificar
- [ ] Item 3: Descrição clara do que verificar
...

## Notas
[Espaço para observações, N/As justificados, sugestões de melhoria]

## Assinatura
Verificado por: ___________
Data: ___________
```

## Regras de Ouro

1. **Nunca pule uma checklist** — Se existe, é porque é necessária
2. **Nunca delete itens** — Marque como N/A e justifique
3. **Atualize quando necessário** — Sugira melhorias via contribution-guide
4. **Não crie checklists para tudo** — Apenas para tarefas que precisam
   de consistência e onde erros têm consequência
5. **Mantenha curtas** — Se uma checklist tem 30+ itens, divida em duas

## Quando Criar uma Nova Checklist

Crie quando:
- O mesmo tipo de erro acontece mais de 2 vezes
- Uma tarefa tem muitos detalhes críticos que são fáceis de esquecer
- A qualidade do output varia muito entre execuções
- Novos membros do squad precisam de guia para garantir padrão
